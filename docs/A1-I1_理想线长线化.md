# A1-I1 理想线大陆长线化（批 I-1：wealth / might / guard）

> 工程 1 · 批 I-1 · 2026-09-11 · 状态：已构建验证，待 bu 实测

## 背景

方向 A 探查发现：8 条理想线（富甲天下/威震四海/守护苍生/探寻真相/自由自在/登临神座/名留青史/以血还血）各仅 4 节点（intro+_1+_2+_3），且全部集中在"自由城邦 · 交汇城"——理想线没有走出自由城，是主线薄弱链最大靶点。

## 本批目标

把 3 条理想线（富甲天下/威震四海/守护苍生）扩展为跨地域践行链：每线新增 7 节点（trip_1/trip_2 + p1/p2/p3 + trial + done），将既有 `goal_<ideal>_3` 出口 go 从 `fc_tavern` 改为旅程链起点 `goal_<ideal>_trip_1`，链尾 done 回 `fc_tavern`（语义等价：里程碑完成后踏上旅程，旅程结束回到原 hub）。

## 新节点内容（三线七节链）

### 富甲天下（wealth）· 南境→东境→承天→铁门关
- `goal_wealth_trip_1` 南境商路驼队（老账房方先生教看货）
- `goal_wealth_trip_2` 黄金城外港（三多：金子/骗子/机会）
- `goal_wealth_p1` 黄金城商会街（三次被拒 → 盘下半间杂货铺）
- `goal_wealth_p2` 银穗商路驿栈（铁锅生意，利钱翻倍）
- `goal_wealth_p3` 承天城官署账房（会算数字更要会算人心）
- `goal_wealth_trial` **铁门关税关**（deep：三倍税钱抉择——识时务交钱，记账不记恨）
- `goal_wealth_done` 自由城码头（收束，置 `ideal_goal_wealth_pursued`）

### 威震四海（might）· 铁门关→第三哨→北境雪原
- `goal_might_trip_1` 北向官道驿站（独眼老兵：稳和狠是两回事）
- `goal_might_trip_2` 铁门关城门洞（投军）
- `goal_might_p1` 铁门关校场（一招败壮汉，教头点醒）
- `goal_might_p2` 第三哨演武场（队正陈三指，半个老兵）
- `goal_might_p3` 雪原战场（替袍泽挡刀，左臂带伤）
- `goal_might_trial` **雪原冰谷**（deep：一换五兽人斥候，四段式战斗——蓄势/贴身滑刀/冰坡借势/压刀钉死）
- `goal_might_done` 自由城广场（名号传回，收束）

### 守护苍生（guard）· 圣辉城→西境→南境→东境
- `goal_guard_trip_1` 圣辉城外城道（卖水汉子替娘还愿）
- `goal_guard_trip_2` 圣辉城救济堂（舀粥半日，掰干粮）
- `goal_guard_p1` 西境元素荒原难民营（让水给孩子，守营一夜）
- `goal_guard_p2` 南境疫村（发药退热，族长送干菜）
- `goal_guard_p3` 东境官道流民队（守一夜的火）
- `goal_guard_trial` **东境隘口**（deep：独挡五劫匪——护流民干粮与孩子）
- `goal_guard_done` 自由城街角（帮卖炭老汉捡炭，收束）
