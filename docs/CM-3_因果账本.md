## 二、检查器

- 文件：`tools\eldacheck\checks\c_causality.py`（elda ci 第 19 个检查器「因果/伏笔账本」）
- 命令：`elda content causality`（与检查器同源逻辑，输出未回收伏笔清单 + 设定词覆盖率）

### 锚点判定规则

| 锚点 | 判定 |
|---|---|
| `flag:<名>` | 该 flag 在 src effects 中被写入（flag:"x" / eff.flag=） |
| `node:<id>` | 节点存在 **且** 被 go/then 静态引用 **或** 运行时 `curNode='x'` 动态跳转 |
| 普通关键词 | 在 src 中出现次数 > 0 |

### 核销逻辑

plant 埋设成立 && reap 回收成立 → `status=closed`；plant 成立但 reap 未达 → open（列入"未回收伏笔清单"，**不拦发布**——伏笔是叙事待回收项；FAIL 仅限账本/设定词缺失）。

### 设定词冻结

20 词（金秤/晨天/鬃吼/腐光/秦·长风/七枚锚/铁牌/神谕/灰鬃/林歌/银月/铁门关/圣山/狼旗/月池/树根/祖灵/大汗/青叶/净化令）必须出现在 game.html（所属卷节点域已并入单文件），缺失即 FAIL。
