## 二、会话字数计数器

- 独立键 `window.__v91sess = {chars, sinceNode}`（**不入存档**，saveVersion=48 与存档结构零改动）
- 流程：
  1. writeNext 渲染正文后 `v91_sessCount(_txt)` 累计去空白字数
  2. `v91_sessRender(node)` 在正文末尾追加"**本段已读 X 字**"（12px 灰色小字）
  3. 节点有选项（到达决策点）且累计 ≥3000 字 → 追加"**这是一个自然的暂存点**"（琥珀色）
  4. 决策点显示后归零（`hasOpts` 判定）；choose 入口亦归零（选择即新起点）
- 开关：无（只读计数器，无副作用；关闭分段阅读不影响计数）
- 引擎锚点：`/v91inj:sessfn/`（函数族）、writeNext 内 `v91_sessCount/v91_sessRender` 钩子、choose 入口 `v91_sessReset`

### bu 实测记录

- 建号开局：`本段已读 319 字` 显示于正文末尾 ✓
- 推进至 pro_after_leave：从 0 重新累计 → `本段已读 407 字` ✓（归零语义正确）
- 模拟累计：chars=3100 → writeNext → `本段已读 3419 字 · 这是一个自然的暂存点` ✓（3000 字提示触发）

## 四、字数审计（elda text len 扩展）

- 原：按段字数分布 + 超长清单
- 扩展：**按卷统计**（节点数/已标/light/deep/epic/均字每段）+ pace 分布合计
- 命令：`elda text len [--min N]`
- ci 门禁（第 20 检查器「节奏与战斗」）：
  - 全库 deep 绝对数 ≥30
  - 叙事卷已标 light 占比 ≤20%
  - 按卷：均字数下限 / light 上限 / deep 下限（配置见 c_pace.py VOL_PACE，依据 v91 实测分布）
  - 战斗四段完整性
