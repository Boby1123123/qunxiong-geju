## 三、扩充记录（扩了什么 / 为什么 / 如何验证）

### 3.1 秤线暗网（本批核心互文设计）
- **扩了什么**：七秤图在不同城市逐步拼合——黄金城地窖七秤图（已圈三杆：西境枯井/沙漠铁箱/东境帛书，第四杆朱笔半画）、学术城《晨天七秤》分布图（七处全列）、魔械城机械秤砣（一城一秤一命）、交汇城冰河秤渡口（秤向北漂）。读书会暗线成形：老砣（黄金城铸秤局）+ 独臂头儿（魔械城炉底帮）+ 老陈（港口城灯塔）+ 费尔曼（学院禁书区），暗号"老磨坊的灯"。
- **为什么**：用户核心诉求是"文本连续性、故事完整性与深度"。秤线是跨 CP 的暗线（西境枯井→沙漠→东境帛书→圣辉城石棺→北境→灰港→南境→学院），CP-14 把南境四城全部织入这张网，让玩家在任意城市都感受到"同一个大秘密在逼近"，同时不触碰七锚/金秤主线判定。
- **如何验证**：bu 实测四入口挂载 true、8 个新节点存在、cp14 事件 20 则入池、出口（fc_road_north/arrive_west_huangyuan/east_chengtian_ruins/north_academy_gate/board_south）全部存在；elda ci 39 检查器全绿。

### 3.2 交汇城补足（原 2 节点 → 20 节点）
- **扩了什么**：原 fc_jiaohui_entry → fc_tavern 仅 2 节点的汇流段，现补 20 节点纵深：广场琴师（信息节点）/布告栏/酒桶/书肆/公会/北行商队/冰河渡口/四向出口。北上引线直连 fc_road_north → 铁门关/学院。
- **为什么**：交汇城是序章后第一个枢纽城市，"在此能听到大陆的声音"才符合枢纽定位；同时给玩家北上/南下/西去/东行四条明确去向。
- **如何验证**：hub_deep_20 四向出口全部真实存在；fc_road_north 链可达。
