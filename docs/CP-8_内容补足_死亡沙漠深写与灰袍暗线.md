## 二、为什么（vol_desert 深写 + 灰袍暗线把秤线串成沙海侧全景）

- **死亡沙漠为全书最薄主地域之一**（dn_demo/dn_clue/dn_ap2 薄域实测），此前只有 BD-2 主干 16 节点 + CP-5 desert_life2 10 节点；本包把沙漠补成“可生活的四段链”：南巷市井 → 驿站旅人 → 神殿封印边缘 → 遗迹收束。
- **灰袍人暗线收束**：承接 dn_west 西境枯井刻字者（“守井人，井不守你，你守井”原句）、教会/北境收铁人路数、CP-6 精灵织梦师与矮人金秤氏钥匙——本包以灰袍人两年前南下沙漠、留铜秤、铁皮筒纸、暗格铁牌为锚，把“秤线”从西境一路铺到沙漠，与七锚/金秤设定互证，不触碰 seal 主线判定。
- **与既有设定严格一致**：盐栈（dn_desert 大井水市/黑市七柱图）、深渊神殿（seal 主线锚点，只观察不干预）、灰袍修士、晨天残墙均沿用既有表述；避开 desert_life2 已有剧情（水市/茶馆说古/守墓人三秤/黑市七柱图/晨天残墙），全部为新写内容。
- **道具链增补**：铜秤（灰袍人所留）、遗迹地图（拓片）、满水皮囊——均独立 flag（cp8_copper_scale / cp8_ruins_map / 皮囊），不入存档结构。
- **防重复**：content dup 0 相似对；新文本无一处与既有沙漠节点句式重复。
