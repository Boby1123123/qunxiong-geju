## 二、登记表结构

```js
{ id:"echo_merchant_saved", flag:"merchant_saved",
  echoAt:["fc_tavern","grad_roam_1","anchor_finale_1"],
  tpl:["……回响句……"] }
```

| 字段 | 含义 |
|---|---|
| id | 登记唯一 id（track_*/echo_* 前缀） |
| flag | 触发回响所需 `S.flags[flag]`（**登记时已全量校验存在**，668 个 flag 全集核对） |
| echoAt | 回响出现的场景节点 id 列表（须为真实节点） |
| tpl | 1-N 条回响句，按 `S.day % tpl.length` 轮换 |

## 三、注入引擎（只读）

- 命中规则：`echoAt` 含当前节点 **且** `S.flags[flag]` 已置。
- 幂等：同节点同 flag 会话内仅注入一次（`window.__e2done[nid+"::"+flag]`）。
- 开关：`S.settings.echoLine===false` 时零注入（关闭后与基线渲染逐字节一致）。
- 只读：不写任何状态；不改变节点语义/选项/判定。
- 审计：注入文本位于正文注入链（记忆/天气/世界书之后）。
