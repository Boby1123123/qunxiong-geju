## 一、目标与设计（为什么做）

**目标**：消除"失败 = 死路或轻描淡写一句"的体验，让失败和成功一样有趣（极乐迪斯科/CoG 设计共性）。玩家判定失败后，进入"失败后可见的边缘世界"——蒙羞离场、遇见正常路线见不到的人、别有天地的际遇，最后自然回接主线，主线不断。

**关键机制发现（零引擎改动）**：`choose` 判定路径（src\script_03.js 核心区）原生支持选项级 `opt.fail` 字段：
```js
const isOk = (lvl==="crit"||lvl==="extreme"||lvl==="hard"||lvl==="normal");
const goId = isOk ? (opt.go||(opt.fail||null)) : (opt.fail||opt.go||null);
```
→ 只需给带 check 的判定选项插入 `fail:"专线入口"` 字段，失败自动走专线；成功仍走原 go。**判定公式 / writeNext / choose 本体 / 存档语义零改动**（red-line 全程未触碰）。
