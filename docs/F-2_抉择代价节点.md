## 设计要点

1. **双态文本**：每个代价节点 text 用 v91_resolveText ifFlag 变体——持有对应 flag 显示完整代价叙事（3 段）；未持有显示"路过偶遇"占位（1-2 段）。世界事件播报是模糊的（"有人传出风声……"），对未持 flag 玩家同样合理，不剧透。
2. **延迟窗口**：代价事件 day = 主线 day + 30~40（95=60+35 / 160=120+40 / 235=200+35 / 290=250+40 / 320=280+40）——给玩家时间消化主线，再让后果上门。
3. **暗线升级**：每则代价文本把 F-1 的暗线要素（圣痕司名录绳结 / 银月商会与钥匙 / 闭眼纸笺 / 金秤铜钱 / 狼牙密信）推进半步，全部为既有设定回指。
4. **选项语义**：选项为"态度锚定"（记住这件事/藏得更深/收好狼牙），go 回 world_continue，不产生新判定。
