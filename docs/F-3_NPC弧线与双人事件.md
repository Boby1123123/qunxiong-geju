## 设计要点

1. **弧线闭环**：每条弧线 4-5 节点完整闭环（相识→秘密→考验→结局），好感变化贯穿（lu_zhao 累计 +21~+34 可至 60 挚友；gu_qingwu 累计 +27；程管事走 flag 非好感）
2. **事件入口**：起始/双人事件挂 EVENT_POOL_EXT（到城触发节点），弧线内部选项推进不依赖多次事件——零引擎改动、零入口挂载风险
3. **ifFlag 变体**：lu_5 结局与 duo_1 对峙均有 flag 感知双态文本（救过/未救、站出/旁观——同一场景不同选择看到不同正文）
4. **暗线聚合**：三条弧线 + 两场对峙全部汇入金秤家之门线索（铜钥匙 / 密档抄件 / 双铜钱 / 矿洞 / 费尔曼书房），与 F-1 暗线（账/铁牌/狼牙）构成回收网，账本 led_f3_* 全部登记
5. **战斗四段式**：lu_4 夜袭码头（周旋非战斗，persu 判定）——不新增 combat 节点，避免 c_combat 校验负担

## 踩坑与修复（重要）

1. **JS 字符串漏 ASCII 闭合引号**：写文本时多处行尾以中文 `。”` 结尾却漏了 ASCII `"` → node --check "Invalid or unexpected token"。用脚本按正则（行首缩进引号 + 中文标点结尾）批量补 15 处。
2. **V66 风格锁"目光"回潮**：新文本 8 处"目光"→ V66 锁 FAIL（38→46）。逐处改写为动作/物象（"看得很仔细，像在认一件旧物"/"脸上没什么表情"/"眼睛在暗处发亮"/"视线"），改完残留 1 处（"收回目光"→"收回视线"），最终 0 处、V66 全绿。
3. **事件池末项缺逗号**（F-2 教训）：wire 脚本内建防护——插入前检查前项尾符，缺逗号自动补，本次无复发。
