## 二、机制

- **S.failRep**：独立键默认 0（旧档兼容）；引擎零结算——蒙羞度由 `f_failpath_*` flag 集合驱动（v91_resolveText node 级 ifFlag，零引擎改动）。
- **蒙羞名号登记（FAILREP_MARKS）**：10 条 `{flag, mark, where, tpl}`——失败 flag → 江湖名号（"铁门关军法官记过名的人"等）→ 名号句。
- **蒙羞被认出（状态感知）**：fc_tavern（军法官新名字）/ arrive_east_tiemen（地道旧案）/ north_library（墨丘利等一页注脚）三节点加 node.ifFlag，flag 命中时正文不同——**text 零改动，只加字段**。
- **失败回响**：ECHO_TRACKS +5——多年后有人还记得你的失败（铁门关名册换三任仍记得你、雪原认路子不认脸、墨丘利那页注脚磨得发白）。
- **蒙羞专属小支线**：
  - 甲「狱中故人」（挂 failpath_warwall_4）：牢中何账房 → 老赵铁匠铺传话 → 人情闭环（收下=done / 退回=denied 双结局）。
  - 乙「蒙羞者集会」（挂 failpath_raid_4）：逃兵村夜莺 → 青桐驿送信 → 雪原散人结盟（接活=done / 拒绝=denied 双结局）。
