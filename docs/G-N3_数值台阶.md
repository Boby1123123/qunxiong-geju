# G-N3 数值台阶（六方向 · 玩法线）

> 批次：G-N3 ｜ 日期：2026-09-10 ｜ 版本基线：v92（saveVersion=48）｜ 状态：已实施并提交

## 一、做什么

为超大型文游补充**数值成长参考层**（只读、不参与判定），让玩家时刻清楚"自己站在哪一阶、该往哪里去"：

- **六档战力评级**：青铜 → 黑铁 → 白银 → 黄金 → 秘银 → 龙晶。
- **战力评分**：属性总和（六主属性 + lv_* 等级键）+ day 主线推进加成（60/120/200/250/280）+ 七锚收集加成（S.anchors 长度×10）。
- **九域难度分级表**：10 区域 × 城市级难度（青铜~秘银），按世界观设定排布（自由城邦新手区 → 沙漠深处秘银 → 兽人圣山秘银等）。
- **战力参考表**：六档攻/防量级 + 注释（明确标注"非判定公式"）。
- **面板 `v92_openTierPanel()`**：顶栏「⚔ 实力」按钮 → 当前评级卡 + 九域难度表 + 战力参考卡。

## 三、关键设计决策

1. **纯只读参考层**：不写 S、不加存档键、不触碰 check 判定公式；评级用于玩家自省与内容规划（后续内容包可按 tier 设计难度），引擎语义零改动。
2. **弹性属性读取**：`S[STR/CON/AGI/INT/SPR/CHA]` 与 `S[str/...]` 双形态 + `lv_*` 前缀遍历，兼容各职业键名差异。
3. **难度表与设定一致**：九域难度贴合 REGIONS 设定（自由城邦新手、北境/铁门关白银、深渊神殿秘银、兽人圣山秘银），不与任何主线判定耦合。
4. **旧档兼容**：无新存档键；S.anchors 存在性用 typeof 保护（旧档无此键则加成 0）。
