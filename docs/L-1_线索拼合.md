## 二、机制（《奥伯拉丁》跨场景拼合 / 公平推理 / 信息双重盲区）

- **碎片大规模化**：三大谜题（旧书下落/深渊之眼/金秤与晨天）各拆 10-11 个 probe，分藏对话、事件、心念（T 联动）、失败线（F 联动）、七锚（M 联动）——全部前期可接触，**不后期追加关键信息**（公平推理）。
- **拼合枢纽**：3 个节点按已集齐数量给不同正文——0-3 茫然 / 4-7 隐约 / ≥7 真相大白（`v93l_assemblyLine` 渲染钩子动态注入，含 █░ 进度条）。
- **拼合结果**：命中数 ≥7 自动置 `clue_assembled` → 枢纽出口出现 ifFlag 变体选项（零引擎改动，复用选项层 ifFlag）。
- **NPC 盲区**：`v93l_npcClue` 按玩家线索进度给不同回应（费尔曼/晨天档案员/灰鬃三处，nTotal≥6 触发，同 place 节流一次）。
