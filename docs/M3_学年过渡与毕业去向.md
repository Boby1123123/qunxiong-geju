## 三、重要修复记录（本批发现并处理）

### 1. ci 三项 FAIL 的根因：elda 检查器用 json.loads 解析 JS 数据块，注入块严禁尾逗号

- 现象：`elda ci` 报 `因果/伏笔账本: 检查器异常 'closed'`、`叙事骨架门 [FAIL] STORY_BLUEPRINT 缺失或解析失败`、`弧线覆盖门 [FAIL]`。
- 根因：
  - c_arc.py / c_skeleton.py 用 `_extract_js_object`（配平大括号）+ `_parse_obj`（剥注释 + 键加引号 + **json.loads**）解析 `window.STORY_BLUEPRINT`；**json.loads 不允许对象尾逗号** → 蓝图注入时 grad_home_8 行尾逗号导致整块解析失败。
  - c_causality.py 运行时 KeyError 'closed'：detail 缺 closed = 账本提取 json.loads 因尾逗号失败返回 None。
- 修复：恢复备份 → 蓝图重注入（扁平属性区尾部，**末项无尾逗号**）→ 账本重注入（items 无尾逗号）→ 断言 CAUSALITY_LEDGER/WORDS 各恰 1 次 → 重跑 ci 全绿（幕5 卷10 章36 弧80 索引4010 锚点35/36；覆盖 3614/4010 90.1%）。
- **教训固化（普适）**：elda 检查器用 json.loads 解析 JS 数组/对象字面量，**注入数据块绝不能带尾逗号**；蓝图扁平属性区注入必须尾补逗号、末项不补。

### 2. 蓝图注入锚错位

- 现象：首次用 `rfind '};'` 锚注入 nodeIndex 失败（SyntaxError），锚点错位插到对象外。
- 修复：改用最后一项锚 `"origin_expand_east_8":{...,type:"main"}},'` 的**扁平属性区尾部** + 尾补逗号注入成功。

### 3. 账本注入首版缺逗号

- 现象：注入 5 项 led_grad_01~05 首版缺逗号 SyntaxError。
- 修复：最终版 `' ,\n'.join(items)` 不加尾逗号重注入；断言 LEDGER/WORDS 各恰 1 次、WORDS 内无 `{id:"led_`。
