# NG-1 多周目变奏（v93）

## 扩充了什么

新增周目回响：`src\data_nodes\dn_ng1.js`（4 节点），零引擎改动、零存档结构改动。

- **触发**：读跨周目档案 `elda-ngplus-v2` 的 history 长度（≥2 回响/≥3 更深记忆），req 内 try/catch 兜底（无档案/异常即 false）
- **ng1_echo**（周目≥2）：城门旧叶似曾相识——收叶为记号或弃之
- **ng1_path**（周目≥2）：城门口知道两条路各通向哪里——"这次你知道自己为什么选"
- **ng1_memory**（周目≥3）：老槐树旧疤与记忆碎片——"有些路，走过了，就忘不掉"
- **ng1_open**（收束）：旧叶夹进册子，与木签、干花并置
- 蓝图：新弧 arc_ng1 + nodeIndex 4 条

## 为什么

多周目系统（u7）已有图鉴与快照，但重开一周目时文本与一周目完全一致，缺乏"这一世不同"的感知。NG-1 用跨周目档案做条件，在自由城入口给老玩家似曾相识的回响——机制上零引擎、数据上零存档结构，却能显著提升多周目重开价值。

- `elda ci` 25 检查器全绿；smoke PASS；四路字节一致；saveVersion=48 不变；旧档兼容
- 治理词自查通过；中文引号成对；死链 0；蓝图 arc_ng1 归属 4/4
- 实测路径：无档案时入口不出现；手动置 elda-ngplus-v2.history 长度 2 → fc_innkeep 出现回响入口
