## 二、设计（极乐迪斯科 · 金·曷城式情感脊梁）

- **搭档人选**：老铁（tie）——第三哨铁匠，F/E/M 链现成关系（救老铁→钥匙→矿洞旧案），哨所/战争/终局天然同在，信任积累有现成路径。
- **无声评判四态**（v93p_judge，只读注入）：tie 好感 ≤-20 敌意 / <60 泛泛 / <80 挚友 / ≥80 深交——四种神态正文（火星溅脚边/让出铁砧/挡着来路/披上皮袄），不评价、只动作。
- **搭档记忆**（E 联动）：命中既有 flag（frontier_key2 / alumni_tie_done / led_anchor_01 / f_failpath_warwall_liu）时追加一句"你还记得……"——搭档记得玩家数年前的选择。
- **S.trust**：独立展示键（好感换算 0-100），applyDefaults 兜底，不进存档结构。
- **⚠️ 边界**：单线剧情角色，未新增随行机制、未改战斗/行动系统、未进入队伍界面——用户红线"同伴队伍系统禁止"零触碰。
