### 2. 双路径机制（S.path / S.subclass）
- `S.path`：generalist（全能·神性线）/ specialist（专精）
- `S.subclass` + `S.subclassCn`：分支 ID + 名称
- **神性线**：generalist → 神话境时继承本职业唯一神神位（陨落神位直接继承/空缺可填补/在位可挑战受封）；specialist → 分支通神者可另辟神座（如黑骑士→深渊之主）
- **一职业一神**（SUBSYSTEM_V48.deity）：奥术之主/晨曦/锻造之神/战神/誓约之神/荒野之神/隐秘之主/太阳神·圣辉/财富之神·金衡

### 3. 分支体系（SUBSYSTEM_V48.general，9 职业 × 3-4 条 = 30 条）
- 法师（元素使/咒法者/秘法学者/死灵学徒）、灵魂法师（通灵者/催眠师/缚魂者）、术士（炼金术士/锻造师/魔械师/血脉术士）、战士（狂战士/武器大师/盾卫/战将）、骑士（圣武士/护教骑士/巡游骑士/黑骑士）、游侠（猎人/巡林者/哨探/兽语者）、盗贼（刺客/夜盗/密探/无面者）、牧师（治疗师/审判官/圣战士/苦修者）、商人（商贾/钱庄主/拍卖师/走私者）
