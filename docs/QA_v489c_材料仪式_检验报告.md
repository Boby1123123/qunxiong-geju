# QA_v489c 补充报告 — 分支进阶材料仪式（35 组）

## 一、范围
在 v48.9b（35 条分支进阶）基础上，为每条进阶挂**仪式材料需求**：材料不足时走"仪式之约→就地采集"自闭环，材料齐备后点燃仪式、消耗材料并结算能力。

## 二、机制

### 1. 进阶节点 req 字段（35 条注入）
`sub_<id>_1` 新增 `req:{mat:"<材料>",n:1}`，由 `v488_go` 跳转时校验：
- **材料不足** → 引导至 `sub_<id>_g`（仪式说明），不进入进阶、不结算
- **材料齐备** → 消耗 1 份 → 进入进阶文本 + effect 结算（幂等 flag `v489_done_<id>`，重复访问不重复消耗/结算）

### 2. 仪式节点（新增 70 个）
- `sub_<id>_g`（35 个）：仪式之约——从导师/工匠/守望者等处的传闻讲清"为什么要这件材料"，选项：就地寻找 / 改日再来
- `sub_<id>_g2`（35 个）：就地采集——对应场景短叙事 + `effect:{mat:...,flag:"v489_got_<id>"}` 得材料×1，回枢纽

### 3. 材料体系（35 种 = 10 种复用 + 25 种新增入图鉴）

## 三、文笔（doubao-human-signal）
- 每件材料一段"传闻"（谁说、为什么需要）+ 一段采集场景（物件、气味、手感），五感俱全
- 对话半句留白、收在动作/物件（"钟正好敲了一下"/"它果然没有回答"），零排比零升华
