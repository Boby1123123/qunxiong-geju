## 一、本批交付内容

1. **9 条职业深渊线仪式化**（08b）
   - `abyss_<key>_1` 挂 `req:{mat,n:1}` 材料前置（深渊封印石/缚魂丝/亵渎铁/血魔之血/黑曜石刀片/腐化獠牙/影丝/倒悬钟印/黑币）
   - 材料不足自动引导到 `abyss_<key>_g`（深渊低语，3 段叙事：深渊侧写+低语指引+材料线索）→ `abyss_<key>_g2`（黑暗场所获取，`effect:{mat,flag}`）
   - 材料足够直接进入仪式，消耗 1 份 + 写"你取出……开始仪式"行
2. **稀有材料市场**（08c，5 节点，sub_path_hub 新入口"夜里出门，去城西的地下材料市场"）
   - `mat_market_hub` 地下市场枢纽（老板娘战立绘/双问门/五去向）
   - `mat_market_buy` 柜台：12 项常规材料明码标价
   - `mat_market_dark` 暗格：8 项深渊材料（倒装锁+黑绒布意象，可买深渊材料跳过仪式获取）
   - `mat_market_swap` 以物易物：5 条换货（`mats` 前置检查）
   - `mat_market_sell` 出货：4 条卖出（loseMat + gold）
3. **图鉴追加**（08a）：ITEM_GALLERY +7 深渊材料（缚魂丝/亵渎铁/血魔之血/腐化獠牙/影丝/倒悬钟印/黑币），深渊封印石复用已有
4. **引擎修复**（本批发现并修复）：
   - `v488_go` 材料消耗幂等 flag 独立为 `v489_consume_<id>`（原复用 `v489_done_<id>`，无 effect 的深渊仪式节点会导致重复扣材料）
   - `choose` 无判定分支：无 `go` 选项点击后 `curNode` 保持（原赋值 `undefined`，会污染 S.choices 并触发异常渲染）
