## 二、引擎设计

- 新全局对象 `AFTERMATH_V50`（IIFE + try/catch，不污染 S 顶层），内容锚点 `/*v50inj:ame*/`
- 新钩子函数 `v50_aftermath(job, realm)`：
  - 以 `S.aftermath[job+"_"+realm]`（值 "seen"）做**单次去重**，同境界只触发一次
  - 渲染"━━ 破境回响 · 晋入X ━━"横幅 + inner-voice 标题 + 叙事段落
  - 有选项 → 渲染选项按钮（onclick：clearOptions → gainText → follow → effect → renderTop/renderStats → "继续前行"按钮 closePanel）
  - 无选项 → 直接"继续前行"
- 挂载点：`v49_finish` 成功分支 `cfg.success.forEach` 之后、addLog 之前，`try{ v50_aftermath(S.job, next); }catch(e){}`
- 新 S 字段：`S.aftermath`（对象，旧档 `if(!S.aftermath) S.aftermath={}` 兜底；不改 S.saveVersion，仍 48）

## 四、过程中问题与处理

1. **商人块 3 处半角引号**（`刻着"学徒"两个字` / `你"赚得干不干净"` / `那句"不看账也信你"的话`）导致 `_chk_2.js` SyntaxError。
   - 第一次精确修复脚本未命中（seg 截取/形态问题）→ 弃用
   - 第二次全量通用正则修复**误伤风险极高**（会把 JS 语法字符串结束引号替换为中文引号，数千处）→ **运行前被 TaskStop 终止，未写入文件**，game.html 保持完好
   - 最终方案：`_v50_fixquotes3.py` 三处精确 str.replace + 扫描确认无残留 → 修复成功（fixed 3）
2. 教训固化：**内容文本一律中文引号；绝不对 3.7M 字符全文跑宽松正则替换**。
