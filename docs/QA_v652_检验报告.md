## 四、关键设计点

1. **强者随军**：名额按军衔（伍长 1 起，元帅 6）；忠诚 = bond/2 + 仁名/10（1-10）；加成按 realm 映射（传奇 +25/大宗师 +15/宗师 +8），伤者减半、俘死不计数——复用 v64 强者加成表。
2. **斗将三选**：应战（v652_duelRoll 判定 + 彩头）/ 遣将（耗忠诚 1）/ 避战（士气 -10）；既有 v65_cmd_duel 本体未动，仅片内入口改接。
3. **俘虏处置**：赎回（名气×50 金）/ 招降（40+roll 判定，成功入 generals 忠诚 3，失败 bond-3）/ 斩杀（凶名+深渊+恩怨账本"杀"级）。
4. **攻城状态机**：围城（粮水周降、断粮士气崩、耗粮加倍、器械进度 +12/周）→ 筹备三选（云梯/冲车/投石）→ 强攻（v652_siegeStorm：v64 分层 ≥85 破城 / 45-69 对峙 / <25 大败）→ 破城三选（屠城/安抚/掠夺，各自 worldFame/双轴/关系/市场落地）→ 战后。
5. **守城事件池** 6 种：夜袭/内应/烧粮/疫病/突围/城破（三选死战/撤退/投降）——玩家在场周结算 8% 触发；不在场围城传闻入 S.missedEvents。
6. **立场事件** 6 条入 campEvents（special 走节点）：嫉妒（喝酒摊开/无视两路）/ 夸赞 / 宿敌同军 / 前辈点拨 / 治伤 / 离营。
