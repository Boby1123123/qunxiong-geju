## 二、设计要点（网络参考落地）

- **CK3 三态结束** → `v654_treatyGen`：白和（win/stale）/ 条款（triumph）/ 灭战条款（annihilate），停战天数沿用 v64（60/90/120）。
- **EU4 战争分数** → `v654_warscore`：wins 差 ×6 + 战线控制均值 + 断粮修正，0-100 归一；终局仍由既有 wins 差触发（不改 w64_warResult 公式）。
- **三国志14 兵站/补给线** → 战线对象带 `supply`：control<20 或攻方断粮 → 补给线断裂，战线每周 -8 回落；`v654_front_cut` 节点联动市场粮价（demand+5）。
- **CK3 盟友贡献** → `v654_alliesCheck`：与一方关系 ≥60 且高于对方 +30 → 援军入列（alliesA/B），7 天一查。
- **历史赔款（法兰克福/凡尔赛）** → `v654_reparTick`：战后分 4 期支付，败方财富账本（W654_WEALTH 本地账，w64 势力对象为 IIFE 内部未导出，v66 联调时并入）→ 胜方，玩家参战胜方获金分成。
