## 五、工程修复记录

**关键问题**：引擎注入点 `// 面板：战争总览` 位于 W64 引擎 IIFE 的 try 块内部（W64 引擎尾部），v655 引擎 IIFE 嵌套在 W64 try 内；其 window 导出语句在 try 外，嵌套解析下块内函数声明未提升到 try 外 → `ReferenceError: v655_curWar is not defined`。

**修复**：将 6 条 window 导出语句移入 v655 引擎 try 块内（紧跟 mediatorRoll 定义后、`}catch` 前）——任何提升语义下均可见。修复后仿真 SMOKE PASS。

**教训（写入本版）**：注入锚点必须确认其所在的 script 作用域边界（是否在某个引擎 IIFE 的 try/catch 内）；导出语句一律放 try 块内。
