## 三、本工程事故记录

1. **半角引号嵌套语法错误（轻，已修复）**：v65_scar_orphan2 文本里 `"他们"` 半角引号导致字符串提前闭合 → 语法 FAIL。修复为「他们」。教训：内容文本引号一律中文「」，内容脚本写完先语法检查。
2. **PowerShell 内联 python 转义踩坑（重复）**：正则/中文片段在 PS 内联 `python -c` 多次转义失败（历史问题复发）——一律写临时 .py 执行。
3. **sim 进程静默退出（环境不稳定）**：node vm 执行大脚本链后进程在部分轮次静默退出（无错误码）——解决：stderr 全量输出 + 结果改 stderr + war 片 existsSync 预检。sim 现已稳定全绿。
4. **军功晋升只升一级（设计修正）**：v65_promote 原一次只升一级，改循环晋升（军功够连升），引擎源与 game.html 同步。
