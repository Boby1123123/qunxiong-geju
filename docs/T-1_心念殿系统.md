## 二、机制（极乐迪斯科 Thought Cabinet 思路）

- **接触**：flag 或 visited 城市满足 unlock 条件 → 概念进入"待内化"列表（不自动内化，需玩家主动）。
- **内化**：设置面板 → 心念殿 → "开始内化" → `S.thoughts[id]={stage:"internalizing",progress:0}`；此后每渲染一个节点 progress+1，满 cost 日 → `internalized`。
- **完成**：永久 buff/debuff（attrs 微调，封顶 80/兜底 5）+ flag `t_<id>_done` + 专属心念正文（v93t_thoughtLine 按 place 关键词注入〔心念·概念〕句，同 place 一次）。
- **独立键**：`S.thoughts` 空对象兜底，saveVersion=48 不变，旧档兼容。
