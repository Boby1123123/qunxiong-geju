**根因**（本批重大发现）：
1. 作者在 JS 字符串内用转义引号 `\"` 写对话，且"开闭交替"但**段末闭引号常借字符串定界符**——纯启发式判断必错，最终采用**元素级独立交替 + 完句条件补闭**。
2. 作者在双引号定界元素内**直接写裸单引号 `'…'` 当对话引号**（1635 个引号）——v90 norm 元素提取正则 `[^"\'\\]` 排除单引号导致**元素被截断**，产生假奇数与漏检。
3. 2 处**嵌套引号**（外层"…"，内层也用"…"）——规范为内层单引号『』层级，并补外层漏闭。
