## 五、踩坑记录（新增实证）

1. **"压低声音"含"低声"子串触发 c_style 防回潮 FAIL**：本批 east_city 插入段"茶客们压低声音议论时"使 game.html 全文字频 低声 74→78（容差仅 +3.7）→ FAIL。修正：改为"茶客们交头接耳时"，Edit 工具直改后重建即绿。教训：写"压低声音/低语"类词前先自查是否含"低声"连续子串。
2. **budget 与 verify 的次序坑（本轮 3 次实证）**：`elda budget` 更新 budget.json 后，若不在其后再 build→copy→chunks→sync，ci 的"权威源幂等 verify"必 FAIL；但 budget 若跑在 build 前，则 baseline 用的是旧 game.html 字节，full 的性能预算门会 FAIL。**正确链 = build → copy → chunks → sync → budget → build → copy → chunks → sync → ci**（或 budget 后完整重建一次再 ci）。已记入 elda-ci-guard pitfalls 待更新。
