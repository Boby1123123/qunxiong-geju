## 五、本批踩坑（重要，已固化）

1. **text 数组末项缺逗号导致 SyntaxError**：tq_expand30.py 的插入点在 `]` 前，当原文末项无尾逗号时，新段与原文末项拼接成同一字符串 → 15 个文件 SyntaxError: Unexpected string。**修复**：插入前检查 `]` 前最近非空白字符，若非 `,` 则 `ins = ',' + ins`（逗号守卫）。此守卫已成 b31 起标准做法（"文本数组末项逗号铁律"的脚本化）。
2. **勿用正则修复缺逗号**：空段 `""` 会被元素间补逗号正则误伤（`"",","` 错乱），且会破坏正常元素。缺逗号一律 git checkout 还原后从源头修。
3. **权威源幂等 verify 的 extract 会用 game.html 覆盖 src**：若 game.html 不是最新 build，verify 会把 src 覆盖成旧版并产生假 FAIL。正确顺序：build → Copy game_built → game.html → verify。chunks/sync 后若 game.html 被改写，需重新 Copy。
