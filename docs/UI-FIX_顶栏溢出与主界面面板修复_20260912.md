# UI-FIX：顶栏防溢出统一适配 + 主界面面板遮挡修复（2026-09-12）

> 批次：UI-FIX_顶栏溢出 · 修改文件：src/gap_00.html（仅展示层 CSS，零引擎/判定/存档改动）

## 背景

用户显示器 1920×1080 @ 240Hz（DPI 100%）。实测发现两处画面问题：

1. **顶栏横向溢出 28px**：v68 主题把 `#topbar` 改为纵向布局（gap_00.html:1099），但早期适配残留未清理：
   - `.title` 残留 `margin-left:44px`（gap_00.html:1006），未被 v93v5 规则覆盖；
   - `.nav` 继承基础样式 `margin-left:auto`（head.html:102）+ 前序 `flex-wrap:nowrap`（gap_00.html:1008），在纵向布局下被推到最右并超出容器；
   - 结果：1280px 设计宽度下 `scrollWidth=1308`，右侧按钮（存档/休整）被裁剪。

2. **主界面三按钮"点不动"**：`#title-screen` z-index=9998（gap_00.html:1262）> `#modal` z-index=900（gap_00.html:1035）。主界面点击「读取存档 / 成就册 / 设定册」→ `v34_openSavePanel` 等 → `openModal` → 面板打开但被 title-screen 完全遮挡，用户观感为"点击无反应"。

## 修复内容（src/gap_00.html）

| 位置 | 修复 |
|---|---|
| v93v5 顶栏块（:1100-1103） | `.title` 补 `margin-left:0;margin-right:0;padding:0;box-sizing:border-box`；`.nav` 补 `margin-left:0;width:100%;flex-wrap:wrap;gap:6px;overflow-x:visible`；`.v44-topbar2` 补 `margin-left:0;width:100%;flex-wrap:wrap`；新增 `#v66-top-logo{margin:0 auto;display:block}` 居中 |
| v94 主界面块（:1261 前） | 新增 `body.v68-theme #modal{ z-index:10000 }`（后置覆盖 :1035 的 900，使面板盖过 title-screen） |
