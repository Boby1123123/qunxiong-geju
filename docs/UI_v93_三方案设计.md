# UI v93 三方案设计（群雄割据 · 西幻桌面端）

> 依据：GitHub 爆火文字游戏 UI 调研（A Dark Room 极简沉浸 / Twine·SugarCube 居中正文+底部选项 / tuesday-js / react-text-game 响应式）、用户实机截图（backup\tmp_user_shot.png）诊断、bu 面板实测（行囊/修炼/日志/势力均居中弹窗，story 空态已由 v92 欢迎主界面填充）。
> 设计目标：**按钮分布合理、面板居中可看可点、正文区不再空白、符合西幻世界观、保留全部既有功能入口**。
> 铁律：不做移动端；saveVersion=48 不变；判定公式 / writeNext / choose / 存档语义不触碰；按钮 id 与 onclick 全部保留（迁移只改样式与布局）。

- 顶栏 23+ 按钮分 4 组（v68-nav-group ×3 + mini 组），中部 v68-announce 世界纪闻条，底部 v68-status 资源栏。
- 弹窗容器 `#modal.show > .v31-modal-container > .box.v68-panel-box`（w=560，水平居中，垂直贴底 y≈650-715）。

## 方案一 · 羊皮卷宗（暖色手稿风）—— 推荐（与现有米色 UI 血缘最近，迁移风险最低）

### 设计理念
承袭 A Dark Room 的"极简 + 渐进"：全屏米白羊皮纸质感，所有信息收纳进"卷轴/书页"容器；顶部一条细徽记栏，导航收敛为一排描金书签按钮；正文区是半展开的羊皮卷轴，选项区在卷轴下方自然收束。让玩家感觉"在读一部装帧精良的编年史"。

### 布局（16:9 桌面）
```
┌────────────────────────────────────────────────┐
│ 徽记栏：标题·纪年·七锚纹章            (h≈48px) │
├────────────────────────────────────────────────┤
│ 书签导航带：地图 行囊 修炼 日志 势力 任务 编年史 │
│             存档 设置（描金书签，hover 浮起）    │
├────────────────────────────────────────────────┤
│                                              │
│        ┌─ 羊皮卷轴（正文区，max-width 42em）─┐  │
│        │  地点行 · 时段 · 章节卡             │  │
│        │  …剧情正文段落（行高 1.8）…          │  │
│        │  选项A 选项B 选项C（卷轴下缘）      │  │
│        └──────────────────────────────────┘  │
│                                              │
├────────────────────────────────────────────────┤
│ 资源栏：100金龙 · 行动4/4 · 4037年 · 地点   (h≈40px)│
└────────────────────────────────────────────────┘
```
- **面板**：全部弹窗升级为"羊皮纸卷宗"容器（圆角纸边 + 金线描边 + 蜡印角），垂直居中（`top:50%;transform:translateY(-50%)`），w 560→640，内部 max-height 78vh 滚动。
- **配色**：底 `#f3ecdc` 羊皮纸、金棕 `#8b6f47`、强调暗红蜡印 `#8a2b1a`、墨蓝点缀 `#2f5f8a`。
- **字体**：标题衬线加粗；正文 16-17px / 行高 1.8；选项按钮 ≥44px 高。

### 落地路径
`src/gap_00.html`：替换 body 背景纹理（CSS 渐变+噪点）、徽记栏与导航带改为书签样式、`.box.v68-panel-box` 改卷宗容器并垂直居中、按钮统一 `.btn` 描金书签；`#story` 欢迎界面升级为"卷轴首页"。

## 方案二 · 暗夜符文（暗色沉浸风）—— 强调叙事沉浸

### 设计理念
借鉴 Twine 沉浸模式 + 暗黑史诗氛围：深蓝黑底、暗金符文、烛火暖橙点缀；正文是"黑暗中亮起的文字"，选项如仪式刻印。适合追求"读小说"氛围的玩家；沉浸模式（I 键）一键只留正文。

### 布局
```
┌────────────────────────────────────────────────┐
│ 极简标题栏：『艾尔达大陆·群雄割据』 + 存档符文     │
│ （左上角竖排微型符文列：地图/行囊/修炼/日志/势力）  │
├────────────────────────────────────────────────┤
│              ▓ 正文区（淡金文字）▓               │
│   左侧光带    段落段落段落        右侧光带        │
│              ▓ 选项：暗金描边 ×3 ▓               │
├────────────────────────────────────────────────┤
│ 资源栏（细线分隔）：100金龙 · 行动4/4 · 自由城邦  │
└────────────────────────────────────────────────┘
```
- **面板**：半透明暗金描边浮窗，垂直居中，毛玻璃底（`backdrop-filter: blur`）。
- **配色**：底 `#0e1420` 深蓝黑、正文淡金 `#d8c48a`、强调烛火橙 `#d97b29`、幽蓝 `#4a6fa5`。
- **交互**：默认非沉浸时顶部细栏 + 左侧符文列（图标化，hover 出文字提示）；沉浸时全部隐藏。

### 落地路径
同方案一文件，但引入 `.theme-dark` 类：body 换深色变量组、按钮换暗金符文、面板换毛玻璃。**风险**：改动面比方案一略大（需覆盖全部既有点击元素配色），但不动任何 onclick/id。

## 方案三 · 阵营指挥桌（策略仪表盘风）—— 信息密度最高

### 设计理念
面向"群雄割据"多势力经营感（类似文明/全战侧栏）：顶部指挥条、左列九域主线、右侧势力任务编年史入口、中央正文垫军事地图纹理。让玩家一眼看到"世界在动"。

### 布局
```
┌────────────────────────────────────────────────┐
│ 指挥条：势力徽记 ｜ 标题 ｜ 战争进度 · 存档 设置  │
├──────────┬──────────────────────┬──────────────┤
│ 左信息列  │   中央正文区          │ 右信息列      │
│ 九域      │   （地图等高线纹理垫底）│ 势力卡        │
│ 主线进度  │   剧情正文            │ 任务入口      │
│ 当前目标  │   选项区              │ 编年史入口    │
│          │                      │ 阵营关系      │
├──────────┴──────────────────────┴──────────────┤
│ 资源栏：100金龙 · 行动4/4 · 4037年 · 自由城邦    │
└────────────────────────────────────────────────┘
```
- **面板**：黄铜描边深色木纹底框，垂直居中，内部三栏式（列表/详情/操作）。
- **配色**：底 `#1c2218` 墨绿黑、深棕木纹、黄铜 `#b08d3e`、朱红图钉 `#a03028`、米白正文。
- **代价**：需新增左右信息列容器与数据渲染（读 S.REGIONS/S.worldWar/S.flags），改动量最大；但对"世界局势"信息展示最强。

### 落地路径
`src/gap_00.html` 加 `#side-l / #side-r` 两列（桌面 1280+ 显示，窗口窄于 1100 自动收进弹窗）+ `script_04.js` 加渲染函数（只读 S，不改存档）。

## 三方案对比表

| 维度 | 方案一 羊皮卷宗 | 方案二 暗夜符文 | 方案三 阵营指挥桌 |
|---|---|---|---|
| 风格 | 暖色手稿/羊皮纸 | 暗色符文/沉浸 | 军事制图/仪表盘 |
| 叙事氛围 | 编年史 · 耐读 | 史诗 · 沉浸 | 策略 · 全局 |
| 信息密度 | 低-中 | 低 | 高 |
| 改动量 | 小（继承现米色体系） | 中（需主题变量切换） | 大（新增双信息列） |
| 与现有 UI 血缘 | 最近 | 中 | 最远 |
| 面板居中 | 垂直居中 ✓ | 垂直居中 ✓ | 垂直居中 ✓ |
| 移动端 | 不做 | 不做 | 不做 |

## 推荐
**首推方案一**（风险最低、最快落地、与世界观"编年史/卷宗"最贴合）；若想要更强沉浸感可后续在设置中提供方案二主题切换；方案三建议作为"世界局势页"的增强而非默认壳。
