## v2 改动内容
1. **背景**：删除半展开羊皮纸卷轴、卷轴木轴、麦穗/剑盾徽记、烛火燎痕、蜡印等全部装饰性图形；仅保留米色羊皮纸底色 + 细腻纸张纤维颗粒凹凸质感（"淡淡羊皮纸屑"）。
2. **旁白区域（新增）**：正文区左侧新增窄栏——栏顶朱红方印、栏内世界事件简报（示例："北境战报 铁门关雪崩，商路中断" / "晨天旧档 秦家档案现于故都地下" / "东境商情 银穗商路通兑暴涨"），细金线分隔、深棕小字；与正文区以细金线分隔。
3. **布局骨架不变**：顶部标题栏+纪年、中部导航带（描金书签按钮）、中央正文区、底部三选项+资源栏（100 金龙/行动 4/4/自由城邦·交汇城）。

- 背景：`src/gap_00.html` body 背景改为纯色 `#f3ecdc` + CSS 噪点/颗粒纹理（`background-image` 用细颗粒 data-URI 或叠加 subtle paper-grain，无任何图形）。
