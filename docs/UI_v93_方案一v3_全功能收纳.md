## 二、约束（落实时）
1. **按钮 id / onclick 全部保留**（布局迁移只改容器与 class，不改绑定；`script_03.js:6260` togglePanel、`script_18.js` UI 绑定、`script_04.js` 动态补丁按钮均不动）。
2. **快捷键 9 键不变**：M地图 B行囊 T修炼 L日志 F势力 Q任务 G强者 C编年史 I沉浸（script_18.js:43 键位表）。
3. **面板零改动**：全部走既有 `openModal` / `#modal.show` 居中弹窗；方案一 v2 已把 `.box.v68-panel-box` 规格为垂直居中 + w 640 + max-height 78vh。
4. **主书签行不换行**：1280 桌面下 9 书签（每枚 ≤84px）+“更多”书签 + 右侧沉浸，单行放得下（总宽 < 1100px）；窗口 < 1100 时"更多"提前折叠，主行仍单行。
5. **旁白栏**（左侧"大陆纪闻"，接 EVENT_POOL_EXT 最近 3 则）仅桌面 1280+ 显示，< 1280 自动收进"更多"菜单入口（btn-world），正文不被挤压。
6. **不做移动端**；saveVersion=48、判定公式、writeNext/choose、存档语义不动。
