## 三、为什么这么扩

- **忠实概念图**：中央大标题+书签行+右上沉浸/更多+左侧纪闻分版块+选项卡片+底部资源栏，逐项对齐用户上传图。
- **纪闻分版块替代单一列表**：概念图左侧是多栏目纪闻（北境战报等），关键词分组让事件按地域归类，世界观更强；day=1 无事件时显示基调句避免空白。
- **更多菜单收纳次级功能**：用户此前指令"把音效、图鉴等不常用内容放进设置/更多"，17 项单列不挤占主界面。
- **不触碰红线**：全部为渲染层 CSS/JS 追加，无引擎判定、无存档结构改动、saveVersion=48 不变。
