# V66 文风规范（叙事连续性 + 文风沉浸感质量工程）

> 版本：V66-ENG（2026-09-08）｜适用范围：《群雄割据》全部新写与改写文本
> 上游约束：doubao-human-signal（物件即记忆 / 对白半句留白 / 克制收尾 / 不排比不升华）
> 本规范是 V66 五方向的"写法层面"标准，与 `情绪外化替换表.md` 配套使用。

---

## 一、总则（一句话）

**写"谁在做什么、世界变成了什么样、你身上留下了什么"，不写"命运齿轮开始转动"。**

事件文本至少回答三件事之一：发生了什么（动作与结果）、谁在场（名字与状态）、世界记住了什么（痕迹与后续）。

---

## 二、五感标准（沉浸感地基）

每个**核心场景**（战争、天灾、政治事件、关键对话、旅行）至少命中 2 个感官通道，且优先"气味 / 声音 / 触感"（视觉最容易堆砌）：

| 感官 | 好例 | 禁例 |
|---|---|---|
| 嗅 | "血腥味混着雪，呛得人睁不开眼。" | "空气中弥漫着肃杀的气息" |
| 听 | "远处号角断在第三声。" | "四周一片寂静"（无对象） |
| 触 | "甲胄贴在背上，汗是凉的。" | "他感到一阵寒意" |
| 视 | "旗烧了一半，另一半月白底还飘着。" | "战况惨烈" |
| 味 | "干粮是霉的，就着雪水咽下去。" | "他尝到了苦涩的滋味" |

规则：感官描写必须**有具体对象**，禁止"气氛 / 气息 / 氛围"这类无指称词。

---

## 三、情绪外化（不直接写情绪词）

情绪一律通过**动作、物件、环境反应**外化。以下直白情绪词在全部文本中禁用：

| 禁用词 | 替换写法示例 |
|---|---|
| 他很害怕 | 他整夜点着灯睡。 |
| 她感到悲伤 | 她把他留下的剑擦了三遍。 |
| 愤怒 | 摔了杯子 / 指节发白 / 转身就走没带门 |
| 震惊 | 手里的信掉在泥里，捡起来也没拍。 |
| 犹豫 | 手按在剑柄上，又松开。 |
| 心凉了 | 他没再开口，第二碗茶放凉了。 |
| 五味杂陈 | （删掉，换成具体两件相反的事） |

全套替换表见 `情绪外化替换表.md`（30 组）。

---

## 四、短句规则（节奏）

1. 单句 ≤ 50 字（超长句拆两句）。
2. 长短穿插：连续三句同长度必改。紧张场景用短句（≤12 字）；余韵场景用一长一短。
3. 段落 ≤ 4 行。战争 / 天灾节点每段 1-2 行。
4. 一个自然段只推进一个动作或一个画面。

---

## 五、留白规则

1. 关键结局 / 死亡 / 告别：写到"物件 + 一句不动声色的交代"即收，不解释意义。
   - 好："他走那天，营门口多了一双靴印。"
   - 禁："他的离去让所有人陷入了深深的哀伤。"
2. 允许玩家不知道全部：传闻只给一半信息（谁、在哪、大概发生了什么），真相留给探查节点。
3. 对话不接满：一方说重点，另一方只回半句，剩余交给玩家的下一个选择。

---

## 六、潜台词规则（对话）

1. 角色不直接说自己的真实意图，用**当前最关心的事**说话：
   - 将军谈战事，会先问粮草；商人谈战事，会先问商路。
2. 同场景多人对话，每人一句且**反应不同**（身份差异决定关注点差异）。
3. 强者对话带"身份印记"：教皇系谈圣谕、北境系谈雪与铁、学院系谈"依据"。

---

## 七、三拍结构（内容密度标准）

核心场景（节点正文）统一三段式，**200-400 词**：

| 拍 | 内容 | 篇幅 |
|---|---|---|
| 引入 | 环境 1 句（含氛围注入）+ 谁在场、什么状态 | 2-3 句 |
| 冲突 | 事件推进：动作、对话、判定前状态 | 主体 60% |
| 余韵 | 结果 + 一个"世界记得"的细节（物件 / 传闻 / 身体印记） | 1-2 句 |

事件类文本最低 3 句（环境 1 / 事件 2 / 余韵 1），禁止单句事件。

---

## 八、群像对白规范（CAST 方向）

1. **每人有标签**：微习惯 / 口头禅 / 执念 / 小目标（W66_PROFILES 四件套）。
2. **同场景差异化**：同一事件，不同角色关注点不同（示例见 v66_cast_warroom / tavern / gate 三样板场景）。
3. **记忆优先**：与 NPC 二次见面，必须引用账本 / 物件记忆（v66_ledgerRecall / v66_objectRecall），禁止重复第一次见面的话。
4. **生命周期可见**：强者状态（健 / 伤 / 俘 / 死 / 行踪）在对话中有 1 句动态交代。

---

## 九、禁 AI 高频词（硬清单）

以下词/句式在全部文本中**禁止出现**（出现即判定文本质量 FAIL）：

微微、陡然、顿时、欲言又止、五味杂陈、眸光微沉、眼神复杂、嘴角勾起一抹、命运齿轮（转动）、不是X而是Y（对比句式）、仿佛（滥用）、不禁、心中一动、若有所思、喃喃自语（滥用）

## 十一、扩展位（≥50% 预留）

- 接续模板位：V66_ENTRY_CONT / V66_HOOKS 可继续追加节点映射（不动既有项）。
- 氛围表位：V66_ATMOS 可按区域 / 节庆新增条目。
- 档案位：W66_PROFILES 可追加到 24+ 名（首批 16 名）。
- 传说位：v66_lore_t9+ 传说可继续追加（对照 v47 势力设定，不新造冲突）。
- 涟漪位：v66_ripple 已按 kind 区分，可新增种类。
