# V68 界面布局规格（颠覆性重做 · 像素级）

> 2026-09-08 ｜ 适配桌面浏览器（实测窗口 967×883）｜ 参考：极乐迪斯科 / 太吾绘卷 / 觅长生 / 鬼谷八荒 / AI Dungeon / 通用 HUD 原则

## 〇、布局总原则（从参考游戏提炼）

1. **四角分工**（觅长生/太吾/鬼谷共识）：重要状态信息放四角，视线易达
2. **正文是主角**（极乐迪斯科/AI Dungeon）：叙事区占屏 ≥60%，永不被打断
3. **面板覆盖不替换**（mob-arena 原则）：背包/角色等面板**滑盖在游戏画布上**，正文保持可见（变暗），玩家从不"被传送到菜单屏"
4. **单一导航**（易次元/太吾 UI 重置）：全游戏一套导航、同一功能同一位置、≤3 次点击到达、随时可返回
5. **行动在底部**（鬼谷八荒/太吾）：选项、操作按钮沿底边排布
6. **键盘优先**（鬼谷键位习惯）：全部核心功能配快捷键

## 二、各区域规格（像素级）

### 2.1 顶部栏（44px，fixed top，全屏唯一导航）

| 位置 | 内容 | 规格 |
|---|---|---|
| 左上 (12,8) | 游戏名「⚔群雄割据」+ 副题「艾尔达大陆」 | 16px 粗体 var(--text-gold)，14px 次要 |
| 中上 (240,8) | `时间 · 地点 · 天气`：4037年·春一月·一日·申时 ｜ ☀晴 ｜ 自由城邦·交汇城 | 14px var(--text-secondary)，三段用 · 分隔；点击可看"今月大事" |
| 右上 (640-940) | **导航图标键 7 个**（44×44，图标+文字竖排或纯图标+tooltip）：`🗺地图 ｜ 🎒背包 ｜ 🧘修炼 ｜ 📜日志 ｜ 🏛势力 ｜ 💾存档 ｜ ⚙️设置` | hover 高亮、active 按压、间距 8px；**全库唯一导航** |

- **删除**：右下角 top-bar-extra 8 键整组；顶部旧 13 键中的「行动/图鉴/成就/魔法/AI润色/潜行」→ 行动=正文区旁的小按钮「⚡行动」，图鉴/成就/魔法并入「日志」下拉，AI润色/潜行并入「设置」
- **快捷键**：地图 M ｜ 背包 B ｜ 修炼 T ｜ 日志 L ｜ 角色 I ｜ 势力 F ｜ 存档 Ctrl+S ｜ 设置 Esc

### 2.2 正文区（主区域）

| 属性 | 值 |
|---|---|
| 位置 | 顶部栏下、底部栏上；left: 16px，right: 侧栏宽（收起 36 / 展开 220）+16px |
| 宽度 | 收起侧栏 ≈700px（占屏 72%）；展开 ≈516px |
| 容器 | `#story`：padding 24px、行高 1.85、字号 17px、字色 var(--text-primary)、最大宽 720px 居中 |
| 文本流 | 标题行（「铁门关·边境村庄」22px 粗体 gold）→ 正文段落（段落间距 14px）→ 打字机 rAF |
| 滚动 | 自动滚动到底；滚轮/拖拽可用；**点击正文 = 跳全文/翻页**（已有） |
| 背景 | 半透明 parchment（rgba(224,212,184,.86)），四周渐变，正文永远可读 |

- 极乐迪斯科把对话放右 1/3 是因为它是"阅读体验优先"；我们正文**居中偏左**（符合中文阅读 + 四角分工），右侧留给状态

### 2.3 属性侧栏（220px，默认收起）

| 状态 | 表现 |
|---|---|
| 收起（默认） | 右侧 36px 竖条：竖排小图标「角色」「六维」「图鉴」「传承」，hover 浮出提示 |
| 展开 | 220px 半透明面板（rgba(232,220,192,.94)）**覆盖在正文上**，正文变暗 20% 但可见（面板覆盖不替换原则） |

展开内容（自上而下）：
1. 身份区：名讳/性别·出身/种族/主修职业/理想/爱好（4 行小字 13px）
2. 状态条：HP 条（红）、SAN 条（蓝）、修为条（金）——条带 + 数值，宽 180px
3. 精简数值：境界/名望/业力/气质/行动点（图标+数字一行一值）
4. 六维折叠区（灵魂/力量/敏捷/智力/魅力/体质，点击展开条带）
5. 按钮行：`[角色卡] [图鉴] [传承] [称号]`（v67-panel 基类按钮）
- 关闭：右上 ✕ / Esc / 再点「角色」图标 / 点击正文（遮罩）
- **正文区永不因侧栏而压缩排版**（覆盖式）

### 2.4 底部栏（110px，选项卡片区）

| 元素 | 规格 |
|---|---|
| 选项卡片 | 每张 高 56px、圆角 10px、边框 1px var(--border)、底色 var(--bg-panel2)；图标前缀（◆推进/ℹ情报/❤关系/💰代价/⭐表达/🔓解锁/⚡行动）+ 文字 15px；成功率标签右下（`成功率68%`，<10% 红字"凶险"） |
| 排列 | 2-4 张横排（等宽 flex），>4 张换第二行；无选项时显示「▸继续阅读…」（v45-cg 保留） |
| 锁定态 | 条件不足：灰化 opacity .45 + disabled + 右下角小字原因 |
| 点击 | 选中卡金色描边高亮 800ms + 其余淡出（v67_uiFeedback 升级版） |
| 左端常驻 | 🪙85 金龙 · ⚡行动 4/4 · 📅第1日（14px 次要色，不占卡片位） |

### 2.5 地图（v67_map v2，全屏覆盖式模态）

- **入口唯一**：顶部栏「🗺地图」+ 快捷键 M；**删除**右下角旧地图、v34_openMap 全退役
- 布局（全屏 900×760 覆盖，正文变暗 30%）：
  - 左上标题「大陆地图」+ ✕
  - 右上：图例（金圈=你所在/实心=已探索/灰❓=未探索/红点=战争前线/⛺=灾城）+ 缩放 +/- 100%
  - 中央：SVG 地图 24 城全可见，城市 = circle(≥10px) + text(地名 ≥12px)；**未探索城市灰点+❓但可见名字**（"传闻中的XX"灰字）
  - 点城市 → 右侧城市卡（420×520 浮层）：名称/简介/危险度/当前状态（围城·疫病·繁荣）/ 按钮[前往][城中各处][关闭]
  - 底部「← 返回游戏」（v67_ui.close，**真 button**）
- 修复项（v67_map 空白 bug）：城市绘制必须读 REGIONS 坐标 + 状态，viewBox fit 带边距，调试探针验证 text≥24 个

### 2.6 势力总览（顶部栏「🏛势力」）

- 列表页（左侧 280px）：已知势力卡片竖排（名称/理念/军事·财富条/关系值色标/状态徽章），未发现势力灰卡"传闻中……"
- 详情页（右侧 500px）：都城/领袖（STRONG_V53 取）/理念/关系史（恩怨簿条目）/强者名单（同 faction 强者：名·境界·状态·bond，点强者 → 强者卡）
- 门禁：序章完成（S.v68PrologueDone）前，列表可用但"加入"按钮灰化 + 提示"主线尚未走完"

### 2.7 模态与面板规范（全游戏统一）

| 类型 | 尺寸 | 关闭途径 | 内容渲染 |
|---|---|---|---|
| 全屏模态（地图/势力详情/图鉴） | 900×760 | ✕/Esc/遮罩/返回游戏 | 打开即渲染（map/org/render* 对接 v67_ui.open） |
| 中面板（背包/角色/修炼/日志/设置） | 620×520 | ✕/Esc/遮罩/返回游戏 | 打开即调 renderPack/renderRealm 等 |
| 确认框（v67_ui.confirm） | 360×200 | 确定/取消/Esc | 标题+正文+两键 |

- **所有面板 = 真 `<button>`**；面板打开时正文保持可见（覆盖变暗）
- 焦点：打开焦点入面板第一个可聚焦元素，关闭回原按钮（v67_ui 已有）

## 三、状态信息放置对照表（哪些放哪，为什么）

| 信息 | 放置 | 依据 |
|---|---|---|
| 时间/日期/天气/地点 | 顶部栏中 | 太吾绘卷资源栏 + 鬼谷小地图位置；全局需常看 |
| 金钱/行动点 | 底部栏左端常驻 | 鬼谷/太吾行动与资源在底边；行动点即"行动力" |
| HP/SAN/修为 | 属性侧栏（可展开） | 极乐迪斯科 HP/士气在左下常驻——我们收敛到侧栏顶部，展开即见 |
| 六维属性/图鉴/传承 | 属性侧栏折叠区 | 觅长生左上修行信息收敛为"角色"抽屉 |
| 世界状态（战争/局势/行情） | 顶部栏中"时间"旁小图标（⚔红点=战争中） | 世界模拟是"后台活"，常驻一角提示，详情进「势力/世界」 |
| 任务/目标 | 「日志」面板 | 鬼谷任务 L 键；不常驻防干扰 |
| 地图 | 顶部栏 + M 键 | 鬼谷小地图 M；大地图是"翻开看"动作 |

## 五、验收（V68 布局版）

1. 全屏唯一导航（顶部 7 键 + 快捷键），无右下角旧键
2. 正文占屏 ≥60%（收起侧栏 ≥72%），属性侧栏覆盖式可折叠
3. 地图 24 城全可见、地名清晰、图例齐全、唯一入口
4. 势力总览（列表+详情+强者）正常、序章门禁灰化
5. 所有面板：打开即渲染内容、✕/Esc/遮罩/返回四路可关、真 button
6. 选项卡片化 + 图标前缀 + 锁定灰化 + 成功率标签
7. 键盘：M/B/T/L/I/F/Esc 全通
8. 无开发者控制台、无空壳面板、无失效按钮、console 0 新错误
9. elda full 新增 c_v68 检查器全绿、四路同步、浏览器全流程回归
