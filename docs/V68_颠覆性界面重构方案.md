## 一、颠覆性设计目标

**目标**：让《群雄割据》达到"顺畅可玩"标准——打开即玩、点啥有啥、回得去、看得清。参考成熟文游（AI Dungeon/橙光/易次元）的核心共识：

1. **叙事是主角**：正文占主屏 ≥70%，一切面板可折叠、可关闭、可返回（AI Dungeon：故事窗口永远是焦点）
2. **单一导航**：全游戏只有一套导航，同一功能永远在同一位置（易次元/橙光一致性原则）
3. **选项是卡片不是文字**：选项与正文视觉分离（Questas 原则#1），点击有锁定与反馈
4. **每扇门都有门槛和出口**：序章后才能入势力；每个面板可关、可回、Esc 可退
5. **地图是工具不是装饰**：城市可见、可点、有图例、有详情
6. **开发者工具永远不露脸**：控制台仅调试模式可见

## 二、V68 七项颠覆性修改（全部实施）

### 修改 1：唯一导航体系（消灭双导航）
- **删除** 右下角 `top-bar-extra` 整组 8 键（角色/背包/修行/职业之路/组织/地图/日志/设置）
- **重构** 顶部栏为唯一导航，图标 + 文字 8 项：`行动｜地图｜背包｜修炼｜日志｜势力｜存档｜设置`（顶部 13 键中「图鉴/成就/魔法」并入「行动」二级或保留图标位，AI润色/潜行移入设置）
- 顶部栏高度 44px，字号 14px，间距统一，hover/active 态齐全
- 右侧属性面板改为**可折叠侧栏**：默认收起为右侧 24px 竖条（点「角色」展开），展开时覆盖在正文上（半透明），不挤压正文

### 修改 2：地图彻底修复 + 重构（v67_map v2）
- **修复渲染空白**：城市节点必须绘制（SVG circle + text 地名，字号 ≥12px），按 REGIONS 坐标 fit viewBox，24 城全可见
- 图例：金圈=你所在 / 实心=已探索 / 灰点+❓=未探索 / 红点=战争前线 / 灾城标记
- 点城市 → 城市卡（名称/简介/危险度/当前状态/按钮：前往·城中各处·关闭）
- 「前往」走真实旅行（travelTo），弹确认（"前往X，预计N日"）
- **删干净**：v34 旧地图（renderMapPanel/双地图）全部退役注释，全库只留 v67_map 一个入口

### 修改 3：势力总览面板（替换组织误绑）
- 新建「势力总览」面板（顶部栏「势力」入口）：
  - 列表页：已知势力（读 ORG_V52 对齐 v47），每势力显示 名称/理念/军事/财富/与玩家关系（-100~100）/ 当前状态（战争中/天灾中/正常）
  - 详情页：点势力 → 该势力 都城/理念/领袖/强者名单（STRONG_V53 同 faction 强者：名/境界/状态/与玩家 bond）/ 关系历史（恩怨簿条目）
  - 未发现势力显示"传闻中有一个势力，但你还没打听到它的名字"（探索感，不剧透）
- **门禁**：「加入学院/势力」入口一律 **序章完成后才开放**（新全局标记 S.v68PrologueDone，序章终节点自动置位）；序章中点击 → 灰化 + "主线尚未走完，此处暂不可入"（human-signal 文本）

### 修改 4：面板系统修复（点啥有啥、看得见、回得去）
- **全库按钮绑定核查**：扫描所有"按钮"元素（button/div/span 带 onclick 或 class=btn），统一为 `<button type="button" onclick="v67_ui.open(...)">`；非 button 且无绑定的 → 修复或删除（输出核查表）
- **panel-wrap 空壳修复**：背包/角色/修行等面板打开时必须渲染内容（renderPack/renderRealm 等与 v67_ui.open 对接，打开即调内容渲染函数）
- **统一关闭**：每个面板顶部标题条带 ✕，底部「返回游戏」，Esc/遮罩点击同出口（v67_ui.close 已建，全面接通）
- **焦点**：面板打开焦点入面板、关闭回原按钮（v67_ui 已有 openDepth，接通键盘）

### 修改 5：开发者控制台生产隐藏
- V35_DevConsole 增加生产开关：`window.v67Debug`（默认 false，仅 URL 带 `?debug=1` 或 localStorage 标记时 true）
- 生产模式：控制台容器 `display:none`，console.log 静音（保留 error/warn）
- 不删代码（保留未来调试），仅运行时隐藏

### 修改 6：选择交互升级（Questas 卡片化）
- 选项渲染从纯文字按钮升级为**卡片**：每选项一张卡（边框 + 底色区分正文），图标前缀（◆ 推进/ℹ 情报/❤ 关系/💰 代价/⭐ 表达/🔓 解锁），文字左对齐，条件不足灰化 + 说明
- 点击后：选中卡金色高亮 + 其余淡出（v67_uiFeedback 已有，样式升级）
- 成功率显示保留（`（技能·成功率N%）`），<10% 加"凶险"标签

### 修改 7：界面统一性（橙光/易次元规范落地）
- 对话框规范：正文区域固定容器（左右边距 24px、行高 1.8、字号 16px、字色 var(--text-primary)），满行换行、垂直居中
- 背景统一：全屏游戏背景（现有米黄 parchment）+ 顶部栏/正文区/底部栏三区固定；所有面板同视觉（v67-panel 基类：同圆角/边框/阴影）
- 深浅主题：默认浅色 parchment，设置可切 theme-night；两套对比度已验（V67_对比度验证表）
- 动效：仅保留 打字机 rAF + 选项高亮 + 面板淡入（0.2s），其余删除（TapTap：宁少勿滥）

## 三、序章流程门禁（玩家明确要求）

- 序章定义：从 `pro_arrive` 到序章终节点（铁门关→交汇城落地，S.v68PrologueDone=true）
- 门禁范围：学院/各势力驻地/职业之路高级分支——序章未完成一律灰化 + 提示"先走完序章"
- 序章完成标记入存档兜底（v68_ensureDefaults，S.saveVersion 保持 48）
- 学院入口改走 v67_gate('academy_enter')：check 改为 `S.v68PrologueDone && 未入学 → 入学线首节点；已入学 → 校内 hub`（failText 区分"序章未完成"与"其他条件不足"）

## 四、落地顺序（P0 先修"不能玩"，P1 重构，P2 打磨）

### P0（本版必须，修完即可顺畅游玩）
1. 删除 top-bar-extra 双导航 + 顶部栏精简为 8 键
2. 地图渲染修复（城市可见可点） + 删 v34 旧地图
3. 势力总览面板（列表+详情+强者）替换组织误绑
4. 序章门禁（v68PrologueDone）+ 势力入口灰化
5. 开发者控制台生产隐藏
6. 面板空壳修复（背包/角色/修行打开即渲染）+ 返回按钮全绑定
7. 属性面板折叠侧栏（正文 ≥70%）

### P1（本版）
8. 选项卡片化 + 图标前缀 + 反馈升级
9. 全库按钮核查表 + 非 button 修复
10. 背景/字体/间距统一（橙光规范）

### P2（下一版）

## 六、验收标准（V68 完成后）

1. 全屏只有一个导航条、一个地图入口、一个势力入口
2. 地图打开：24 城全可见、地名清晰、点城市出卡、前往真实旅行
3. 点势力：势力总览（已知势力 + 详情 + 强者名单）；序章前灰化提示
4. 任意面板：打开有内容、✕/返回游戏/Esc 三路可关、关后回原处
5. 正文区域占屏 ≥70%，属性侧栏可折叠
6. 界面无开发者控制台、无空壳面板、无失效按钮
7. 序章流程：点学院/势力 → 提示先走完序章；序章完成后可正常加入
8. elda full 全绿（新增 c_v68 检查器：导航唯一/势力面板/门禁/地图节点/控制台隐藏）
9. 四路同步字节一致 + 仿真断言扩展 + 浏览器全流程回归
