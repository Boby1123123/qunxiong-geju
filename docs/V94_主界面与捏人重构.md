## V94c 修补（2026-09-12 · 用户反馈"取消限定高度仍看不到第肆步/按钮"）

- **问题**：max-height + sticky 方案在用户视口下仍不奏效——内容区高度受限但滚动不直观，sticky 导航依赖页面滚动才吸底，捏人 modal 内不滚动时按钮仍被推出视口。
- **修复（彻底方案，纯 CSS）**：`#creation-shell` 改为 **`position:fixed; inset:0` 全屏 + flex column**：
  - `.c-head`/`.c-steps` 固定顶部（flex:0 0 auto）；
  - `.c-body` **flex:1 1 auto; min-height:0; overflow-y:auto**——内容区自适应占满剩余空间（**取消固定像素高度**），超长才内部滚动；
  - `.c-nav` **flex:0 0 auto 物理固定在界面底部**（不依赖 sticky/页面滚动）——按钮任何步骤、任何视口都可见。
