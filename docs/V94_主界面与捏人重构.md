## 扩了什么（Why）

1. **游戏入口直通捏人的问题**：原 `init()` 无存档时直接 `showCreation()`，用户一打开游戏就进捏人，没有"游戏开始"仪式感，也缺少常规入口（读档/成就/设定）。
2. **捏人界面不美观**：旧捏人界面的 `sel-card / attr-row` 等类**从未有对应 CSS 定义**——裸按钮无卡片样式、无分步、无预览，与后续剧情（序章 2.0 九出身 / 学院 / 七锚之约）缺乏"此行将引向"的交代，选项与故事衔接生硬。
