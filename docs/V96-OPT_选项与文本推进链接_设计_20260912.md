## 一、Schema 扩展（节点 options 新字段，全部可选、向后兼容）

```js
options:[
  {
    text:"...",
    // A1 条件显隐（声明式；与既有 o.req 函数并存，cond 优先级低于 req）
    cond:{ flag:"x", flagNot:"y", skill:{k:"str",op:">=",v:8}, rel:{id:"npc_id",op:">",v:50},
           job:"骑士", place:"自由城", day:{op:"<=",v:120}, reason:"力量不足" },
    // A2 组合判定（双属性，三档结果）
    dual:{ a:{k:"str",v:8}, b:{k:"will",v:8}, dc:55,
           tier:{ pass:{go:"node_pass"}, part:{go:"node_part"}, fail:{go:"node_fail"} } },
    // A4 一次性（点击后记录 S.flags["opt_<node>_<idx>"]，跨会话）
    once:true,
    // A5 时间敏感（day 窗口，过期换文案）
    expire:{ day:120, locked:"城门已封，无法出城。", lockedText:"（城门已封）你终究没有出城。" },
    // A6 隐藏（默认不渲染；解锁后出现）
    hidden:true, unlock:{ flag:"x" },   // 或 unlock:{ probe:true }（探索动作设 flag 后解锁）
    // A3 后果预览（自动推导：effects/changeRelation/time/go；也可手写覆盖）
    preview:"将推进 2 日；与金秤家族关系 +5"
  }
]
```

## 二、12 项技术方案与接入点（均不触碰红线）

### A 组 · 选项类型升级

| # | 功能 | 接入点 | 实现要点 |
|---|---|---|---|
| A1 | 条件显隐 | showOptions（script_03.js:600）内调用新模块 `v96_optGate.filter` | cond 声明式判定（flag/skill/rel/job/place/day）；不满足 → `opt-locked` 灰锁 + title 原因 + 点击提示（复用现有 `o.req` 的锁形态）；**不改 choose** |
| A2 | 组合判定 | showOptions 的 onclick 前检测 `o.dual` → 走新函数 `v96_dualResolve`（**完全旁路 choose**，零触碰判定公式） | 计算双属性值 → 通过 2/1/0 个 → 取 tier.pass/part/fail → 复用既有结算与推进（travelTo/effects） |
| A3 | 后果预览 | showOptions 渲染时 | 选项旁小字/悬停 title：`⏱+2日 · ♥金秤+5`；由 o.effects/changeRelation/time/go 自动推导，o.preview 可手写覆盖；纯渲染层 |
| A4 | 一次性 | showOptions 过滤 + onclick 记录 | `S.flags["opt_<node>_<idx>"]`（S.flags 既有结构加键，applyDefaults 兜底链不变）；重访灰锁"你已做过这个选择" |
| A5 | 时间敏感 | v96_optGate.filter | `S.day > o.expire.day` → 灰锁 + 过期文案 o.expire.locked/lockedText |
| A6 | 隐藏 | v96_optGate.filter | `o.hidden && !解锁` → 不渲染；解锁（flag/probe）后正常显示 |
