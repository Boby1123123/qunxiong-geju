# X-2 行动日志持久化 + 冒险手记联动

> 批次：X-2 ｜ 日期：2026-09-11 ｜ 状态：已完成并验证
> 前置：ACT-1 行动日志容器 #v93-actlog（src\script_04.js act IIFE，:11123 起）

## 一、目标

- 行动日志跨会话留存：刷新/重启后历史日行动可回看（不依赖存档结构）。
- 与 I1-3 冒险手记（elda-journal-v3）联动：手记按天分组回看时，同日行动流水嵌入每日条目下方。

## 二、设计

### 存储键 `elda-actlog-v2`（独立 localStorage 键，非存档结构）

- 条目：`{day, cls, html}`；cls ∈ res/risky/noind/hint/feel/warn。
- 内存 `__v93ActLog` 渲染数组上限 50 条（滚动淘汰最旧）；持久化 `__persist` 上限 300 条（同日合并当日，超出按日淘汰最旧）。
- 保存时机：pushLog 时同步写 localStorage（saveStore）。
- 清空：`window.v93_clearActLog()`（日志区头栏"清空日志"入口，同时清 DOM 与持久化）。

### 手记联动（v74_openJournal 内 /x2inj:actlog-link/）

- 手记每日条目（第 N 天·地点）下方，按 `day` 过滤 `elda-actlog-v2`，倒序嵌入当日行动流水（12px 灰字、独立于手记正文）。
- 手记仍是剧情节点快照，行动日志是操作结果流水，二者并存不互写。
