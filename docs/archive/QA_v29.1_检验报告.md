## 二、核心工具验证详情

### 1. 统一检查工具（check_unified.py）

**检查项（5大类）**:
- 引用检查：区分真正死链/预留扩展位/动态拼接
- 结构检查：place/text/options完整性
- 语法检查：node --check验证4个script块
- 重复定义检查：同一节点ID定义多次
- tier格式检查：是否使用引擎兼容格式

**验证结果**:
```
[1/5] 引用检查: 真正死链386个, 预留扩展位1个, 动态拼接9个
[2/5] 结构检查: （快速模式跳过）
[3/5] 语法检查: script[0-3] 全部 PASS
[4/5] 重复定义: 23个
[5/5] tier格式: （快速模式跳过）
耗时: 0.4秒
```

**改进点**:
- 相比v29的check_references.py（244死链）和traverse_test.py（389死链），统一工具合并了两者功能
- 区分三类引用：真正死链（红色错误）/预留扩展位（黄色警告）/动态拼接（蓝色提示）
- 减少误报：预留扩展位不再算错误

### 2. 自动修复工具（auto_fix.py）

**可修复错误类型（8类）**:
1. 选项用text:而非t: → 自动替换
2. tier格式错误 → 转换为引擎兼容格式
3. 缺少闭合大括号 → 自动补全
4. 引号不配对 → 自动修复
5. effect数字加引号 → 自动移除引号
6. 节点ID用单引号 → 自动替换为双引号
7. 多余逗号 → 自动移除
8. Python注释混入JS → 自动移除或转换

**实际修复验证**:
```
[扫描] 发现 64 个数据卷
[检测] 发现 101 处可修复（16个文件）
[备份] 自动备份 64 个文件为 .bak
[修复] 成功修复 101 处
[验证] 构建成功
```

**修复分布**:
- story_elda_ba.py: 15处（text:→t:）
- story_elda_be.py: 13处
- story_elda_bg.py: 16处
- story_elda_bh.py: 14处
- story_elda_bf.py: 10处
- 其他11个文件: 33处
- 多余逗号: 3处

**安全机制**:
- 默认--dry-run预览模式，不修改文件
- --execute模式自动备份为.bak
- 修复后自动运行构建验证，失败自动回滚
- 支持--rollback回滚到备份版本

### 3. 统一CLI入口（elda.py）

**命令列表（14个）**:
```
build       构建+语法检查+错误定位
check       完整检查（引用+结构+语法+重复+tier+存档兼容）
fix         自动修复常见语法错误（预览/执行）
compile     YAML→JS编译
decompile   JS→YAML反向转换
index       生成节点索引
graph       生成节点关系图（支持--theme主题筛选）
test        自动化遍历测试
save-test   存档兼容性测试
devpanel    注入开发者面板到game.html
release     一键发布
restructure 项目结构重组（危险操作，需确认）
info        显示项目信息
help        显示帮助
```

**验证结果**:
- `elda.py build`: 0.8秒，4个script全部PASS
- `elda.py check --quick`: 0.5秒，5大类检查完成
- `elda.py fix`: 0.2秒，扫描64个数据卷
- `elda.py info`: 0.1秒，显示项目信息
- `elda.py graph --theme seal`: 0.1秒，生成七印线关系图

- 性能优化：关闭持续物理模拟、简化边渲染、标签默认隐藏、拖动时隐藏边

### 5. JS→YAML解析修复（js_to_yaml.py）

**问题**: 原正则要求`function(){return{`紧挨着，实际代码中有空格/换行，导致只解析到7个节点。

**修复**: 
- 正则放宽为只匹配`N["id"]=function(){`
- 在函数体内搜索`return {`的位置
- 支持空格、换行、不同格式

**验证结果**:
```
修复前: story_elda_ak.py 解析到 7 个节点
修复后: story_elda_ak.py 解析到 15 个节点
提升: +114%
```

3. **JS→YAML解析率**: story_elda_ak.py从7→15节点，但仍非100%解析，部分复杂节点可能跳过
4. **关系可视化器**: 全量1609节点仍可能卡顿，建议使用--theme筛选
