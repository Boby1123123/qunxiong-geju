# QA_v31 检验报告 — UI与函数模型超大规模重构

## 一、版本信息

## 二、修改内容清单（5大方向）

### 方向一：按钮系统全面重构
- **三级按钮层级**：
  - `.btn-primary`：金色渐变主按钮，最突出
  - `.btn-secondary`：深灰渐变次按钮
  - `.btn-ghost`：纯文字三级按钮
- **返回按钮专门美化**（`.btn-back`）：
  - 左侧←箭头图标
  - hover时箭头左滑4px
  - 底部金色装饰线（hover时宽度80%）
  - 44px高，符合无障碍标准
  - 金色边框+hover发光效果
- **选项按钮美化**（参考Disco Elysium）：
  - 左侧▸箭头，hover变▶并右移
  - 渐变背景+彩色左边框（战斗红/对话蓝/修炼紫/探索绿/金色）
  - 已访问选项半透明+✓标记
  - hover时左内边距增加+阴影
- **按钮涟漪效果**：点击时从中心扩散的白色涟漪
- **所有按钮统一**：圆角8px、padding、字体、transition

### 方向二：模态框系统统一重构
- **统一容器**（`.v31-modal-container`）：
  - 深蓝渐变背景（160度）
  - 金色细边框（rgba(240,214,138,.18)）
  - 多层阴影（外阴影+内高光）
  - 圆角12px
  - 弹性打开动画（scale .92→1，cubic-bezier）
- **遮罩升级**：
  - 半透明深蓝背景（rgba(5,10,20,.75)）
  - backdrop-filter: blur(6px) 毛玻璃效果
- **标准化底部**：
  - 所有弹窗自动添加"← 返回游戏"按钮
  - 顶部边框分隔线
  - 按钮居右
- **统一关闭方式**：✕按钮 + 底部返回 + ESC键 + 点击遮罩

### 方向三：字体与排版系统
- **引入Google Fonts**：
  - Noto Serif SC（标题衬线，400/600/700/900）
  - Noto Sans SC（正文无衬线，300/400/500/700）
- **字体层级**：
  - 标题/模态框标题/地点名：衬线字体，letter-spacing 2-4px
  - 正文/按钮：无衬线字体
- **排版节奏**：
  - 正文16px，行高2.0（32px），letter-spacing 0.5px
  - 段落间距16px，首行缩进2em
  - 地点标题居中金色衬线，字间距4px
  - 分隔线居中金色衬线，上下边框
- **NPC对话**：衬线斜体+金色左边框+渐变背景

### 方向四：动效与微交互
- **模态框打开**：scale(.92) translateY(20px) → scale(1)，弹性曲线
- **按钮hover**：translateY(-1px) + 阴影加深
- **按钮active**：translateY(0) + 涟漪扩散
- **选项hover**：左内边距增加 + 箭头右移 + 左边框变金
- **返回按钮hover**：箭头左滑 + 金色下划线展开 + 发光
- **遮罩**：backdrop-filter淡入

### 方向五：UI专项检查工具
- **新增tools/ui_check.py**：
  - CSS变量完整性检查
  - 按钮样式完整性检查
  - 模态框样式检查
  - 字体样式检查
  - 硬编码颜色检查
