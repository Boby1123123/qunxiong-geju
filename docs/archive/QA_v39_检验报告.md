## 四、发现的 Bug 与修复

| Bug | 根因 | 修复 |
|---|---|---|
| `Uncaught TypeError: Assignment to constant variable`（game_check.html:67626） | v39 插入的 BOSS 敌人定义用了 `ENEMIES = Object.assign({}, ENEMIES, {...})`，而 `ENEMIES` 为 `const` 声明，重新赋值抛错并中断整个 script 块（后续节点全部不注册） | 改为 `Object.assign(ENEMIES, {...})` 原地扩展 ✅ |
| 6 处战斗调用敌人 ID 传错 | `startCombat("dun_books_3","未知敌人","dungeon_hub")` 把**节点ID**当敌人ID，导致 `ENEMIES[enemyId]` 取不到敌人，战斗静默失败 | 修正为 `startCombat("dun_books_boss","墨噬","dun_books_treasure")` 等 6 处，战后节点指向各副本宝藏节点 ✅ |
