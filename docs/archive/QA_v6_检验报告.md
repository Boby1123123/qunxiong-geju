## 一、本轮新增内容

### 1. 六动作函数全面重写（乌贼风格六档差异化叙事）

对城市六动作【打探/探索地标/修炼/接委托/拜访势力/打探秘密】进行整体重写，每个动作从"四档合并+两档合并"改为**六档完全差异化**：

| 档位 | 叙事特征 | 示例（修炼） |
|---|---|---|
| 大成功 crit | 顿悟/超额/被引为上宾，含额外线索 | "烛火跳了一下然后定住……气机沉入丹田像水滴落进深井……这一坐抵得上平日数日之功" |
| 极成功 extreme | 干净利落/管事亲见 | "气息渐渐绵长……气机走了一个完整周天没有滞涩" |
| 困难成功 hard | 曲折但办成/有所得 | "起初心浮后来慢慢沉下去……像暗室里摸到墙的轮廓还没找到门" |
| 普通成功 normal | 中规中矩/平稳 | "盘膝吐纳气机平稳……修行大多是这样的日子——平平无奇，却一日不可少" |
| 失败 fail | 无所得/被挡驾，但不羞辱 | "心浮气躁……越收越乱……窗外的天已经暗了" |
| 大失败 critfail | 心魔窥隙/被盯上/得罪人，**必含补救路径** | "耳边骤然响起一声冷笑……是你自己心里的——那个你一直不愿面对的部分……补救：休息几日，或找一处清净之地，或服一颗安神的药" |

### 2. 判定过程演出（禁止掷完直接跳转）

每个动作严格遵循：**环境先行（物象/氛围）→ 动作描写 → d100 判定 → 六档剧情演出 → 明确得失（applyEffects + res 行）→ 衔接回城市**。

示例（打探 extreme）：
> 你挑了个不惹人注意的角落坐下，要了壶最便宜的茶，听了半个时辰。
> 茶棚里一个裹着旧棉袄的脚夫说漏了嘴：银月商会的车队最近夜里也在赶路，车上蒙着黑布，押车的都佩了刀。
> ◆ 结果：+10修为，+1声望。

### 3. 设定缓展开

打探情报池从"一次性罗列5条政治情报"改为**每条只含一个信息点**，通过具体人物（脚夫/马夫/卖炭老汉/酒馆老板娘/精灵行商/卸货工头）和场景带出，不灌输。

### 4. 失败叙事有意义、不羞辱、保留补救

所有 critfail 分支均含**明确的补救路径**（花钱消灾/换城/将功补过/找引荐人/休息服药），不给致命伤（critfail 后 hp>0），不使用羞辱性表述。旅行事件池 14 条全部通过"无羞辱性表述"检查。

### 5. 存档隔离

ruleset_id 从 `elda-qunxiong-v2` 升级为 `elda-qunxiong-v3`，旧版本存档自动隔离，不影响新内容。

## 四、剩余缺口与后续建议

### 已知缺口
1. **序章/城市剧情节点的文笔**：story_elda_b~d 中的剧情节点（序章税吏、各城 arrive 节点）质量已较好，但未逐节点按六档标准重写。当前六动作函数是最高频调用部分，已优先覆盖。
2. **战斗系统**：当前以判定+叙事为主，未实现独立的回合制战斗引擎（40 号设定的战略/战术/表现三层）。
3. **NPC 离线生活的具象化**：worldTick 已推进 NPC 状态，但缺少"你离开后某 NPC 做了什么"的具体叙事回调。
4. **音效**：环境音效框架已搭（syncAmbient），但实际音频资源未嵌入（单文件 HTML 体积考虑）。
5. **移动端适配**：UI 以桌面端为主，移动端触控体验未专项优化。

### 后续迭代建议
1. **v7 内容扩充**：按地区扩充城市专属剧情节点（当前 163 节点，目标 300+），每个主要城市至少 3 个专属事件。
2. **战斗引擎**：实现 40 号设定的三层战斗（战略层布阵/战术层回合/表现层描写），与 d100 判定对接。
3. **NPC 日程系统**：13 号设定的离线生活具象化，玩家回到某城时触发"你走后发生了什么"的回调叙事。
4. **多周目继承**：真·多周目（通关后继承部分声望/知识/物品，开启新对话选项）。
5. **美术增强**：地图 SVG 从简笔画升级为带地形纹理的版本，城市图标差异化。
