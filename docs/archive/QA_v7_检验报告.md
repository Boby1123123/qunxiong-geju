## 一、新增内容

### 1. 战斗系统（40号设定·战略/战术/表现三层）

**战略层——战力差定基调**
- `playerPower()`：基于境界基准战力 × 职业修正（战士1.2/法师1.1）× 状态修正（残血0.7/半血0.9）
- `combatTone()`：战力差百分比 → 五档基调（oneshot秒杀/crush碾压/advantage优势/slight微差/equal均势）
- 高境界敌人触发境界可视化（宗师境灯火倾斜/大宗师领域展开声音消失）

**战术层——d100攻击检定**
- `attackRoll()`：d100 + 净修正（战力差换算 0/±10/±20/±30/±40）≥ 50 命中
- 六档结果：大失败(自然骰≤5) / 暴击(≥96) / 完美命中(≥80) / 普通命中(≥50) / 擦伤(≥35) / 未命中
- `calcDamage()`：基础攻击 − 防御×0.3，乘以伤害倍率（暴击2.0/完美1.5/普通1.0/擦伤0.5），战力差加伤
- 支持优势/劣势双掷（职业技能触发优势）
- 防御动作：减伤+反击姿态
- 逃跑：AGI+潜行 d100 判定，失败受8点伤害

**表现层——乌贼风战斗描写**
- `COMBAT_TEXTS`：开场基调5种 / 攻击结果6种 / 受击4种 / 技能5种 / 境界可视化3种 / 胜负3种
- 每场战斗严格遵循：环境先行 → 动作拆解 → d100判定演出 → 六档差异化描写 → 明确伤害数字 → 敌方回合 → 衔接
- 胜利有代价（护甲碎/新伤/力竭），失败不封死（重伤被救/损失30%财物/声望-3）

**敌人数据**（ENEMIES，12种）
- 凡人境：山贼/饿狼/地痞
- 启灵境：暗蚀会爪牙/兽人战士/雇佣兵
- 凝元境：暗蚀会执行者/精锐卫兵/巨兽首领
- 化意境：暗蚀会队长/沙场老将
- 宗师境以上：暗蚀会部门主官/传奇武者（不可正面对抗，触发desperate模式）

### 2. NPC离线生活具象化回调（13号设定）

**NPC_LIFE 数据**（8位NPC，每人4-5条离线生活事件）
- 5位天骄：艾尔达里翁·埃翁（自由城邦/时空天才/旧怀表苦茶下棋）、罗兰·德·艾恩沃尔（北方/铁壁继承人/打铁骑马）、西尔维娅·冯·墨丘利（南方/银月家族/珠宝跳舞品酒）、斯卡迪·弗罗斯特（北境/冰霜女武神/打猎木雕民谣）、米迦勒·德·本尼迪克特（教会/圣光骑士/园艺孤儿院）
- 3位通用NPC：灰港酒馆老板娘/北境铁匠/南方商会管事

**回调机制**
- `npcLifeCheck()`：玩家到达城市时自动触发
- 记录 `S.world.npcStates[npcId].lastVisit`，计算经过天数
- 按天数范围（1-3/4-7/8-14/15-30/31+天）匹配对应离线生活事件
- 已触发事件去重（`seen` 数组），同一事件不重复
- 输出格式：`── 你走后的这些天 ──` → NPC名 → 事件叙事（只展示结果不展示过程）→ `【痕迹】xxx` → 效果（业力/声望/财物）
- 痕迹展示原则：伤疤/新物品/情绪变化/环境痕迹/第三方转述，让玩家自行拼凑真相

## 四、剩余缺口与后续建议

1. **战斗AI**：当前敌方回合只有普通攻击，未实现敌人技能释放（暗蚀会爪牙的"暗影匕首"/侵蚀触等技能已在数据中定义但未在战术层调用）。后续可在 `combatEnemyTurn()` 中加入技能选择逻辑。
2. **战斗动画**：当前为纯文本演出，可后续加入CSS动画（震动/闪红/伤害数字弹出）。
3. **NPC关系账本**：当前实现了离线生活痕迹展示，但"关系变量介入对话"（如NPC的朋友突然来找、表情变化）尚未完全实现，可在后续版本中加入对话选项的 `req()` 条件分支。
4. **更多敌人**：当前12种敌人，可按地区扩充（精灵区敌人/矮人区敌人/沙漠区敌人）。
5. **战斗掉落**：当前战利品为固定值，可后续加入随机掉落表和词缀系统（复用已有词缀模块）。
