# 世界设定 v64 — 活世界模拟层

> 版本：v64（在 v63.5 基础上）；载体：game.html + chunks/v62_world.js（w64 前缀分片）
> 引擎 marker：`/v64inj:engine/`；内容 marker：`/v64inj:content/`；钩子 marker：`/v64inj:hooks/`（tick×2 + ensureDefaults×2）；面板 marker：`/v64inj:panel/`（v57 职业之路 + v51 修行面板各一）
> 铁律：不触碰判定公式 / writeNext / choose / 存档语义；新系统全部经既有钩子接入。

## 一、设计目标

玩家不管，世界也在变；玩家管了，世界记得。《群雄割据》从"玩家中心叙事"升级为"玩家参与的世界模拟"。

## 三、战争与冲突（wars / w64_battle）

七阶段时间线（每周推进）：宣战（起因事件→公示）→ 集结（征兵 3-5 周，前线围城）→ 拉锯（每周战役结算）→ 转折（战果阈值）→ 终局（和谈/灭战）→ 结束（世界状态落地 + 编年史）。

胜负结算公式（对照三国志士气/断粮 + NGA 分层）：

```
军力 = 势力军事值 + 出征强者加成（传奇+25/大宗师+15/宗师+8，从 STRONG_V53 同势力取）
     + 玩家加成（参战按境界 +3~15；提供物资+5；煽动内乱 -10 对方）
士气修正：断粮 -30%、连败 -10/场、主场 +10、天灾 -15
结算：1D100 + (atkStr-defStr)/2 + 士气差/10
分层：≥85 大捷（敌方丢城）/ 70-84 小胜 / 45-69 对峙 / 25-44 小负 / <25 大败
战后：胜方士气 +5、败方 -5；战场事件池按分层抽 1（残军劫掠/名将单挑/敌营内应/瘟疫/宝物出世）
```

- 玩家介入：世界面板"奔赴前线" → w64_war_join 节点（领军牌加入/观战/离开）
- 参战（S.w64Side）后每周 w64_battle 自动带玩家加成结算，战果写 history
- 辐射：前线城市繁荣度 -、商路封锁（经济联动）、同势力强者行踪强制"征战"（v56）、战后 5% 受伤 / 1% 陨落（写 STRONG 扩展位）

## 四、天灾与异常（disasters / w64_tickDisasters）

调度器（对照 Occurrences：概率触发 + 递增结束 + 记忆期）：

| 类型 | 触发概率 | 持续 | 效果 |
|---|---|---|---|
| 兽潮 | 北境 1.5%/周 | 14-49 天 | 区域封锁、粮食减产、游侠任务+ |
| 瘟疫 | 南境 1.0% + 战时 3% | 同上 | 城市隔离、牧师/术士可缓解 |
| 深渊裂隙 | 1.0% ×(corruption/50) | 同上 | 封印线联动、深渊强者行踪出现 |
| 元素风暴 | 西境 0.5% | 同上 | 法师弧"元素失衡"联动 |
| 旱涝 | 东境 0.8% | 同上 | 粮价暴涨、难民潮 |

结束判定：每周 10% + 每多一周 +10%；结束后 60-80 天记忆期不重复。
玩家响应四选（w64_dis_respond → rescue/loot/study/leave）：救援（mercy+8/purity+5）、掠夺（terror+8/corruption+5/gold+80）、研究（scholar+6）、逃离（无后果但留传闻）。

## 五、教廷政治（politics.papacy）

- 教皇沉眠 → 枢机团选举（30-60 周一次）：候选 枢机·克莱门特（严守教条）/ 枢机·奥黛拉（开明宽恕）
- 玩家影响：游说（组织 rank）、资助（200 金 +10 favor）、舆论（名声）、暗杀（深渊线）
- 当选：教廷-各势力关系重排（church-academy ±15），宗教政策影响职业待遇

## 六、市场模型（market / w64_tickMarket）

| 商品 | base | 波动 | 需求修正 |
|---|---|---|---|

- 目标价 = base × (0.5 + demand/supply × 0.5)，clamp 10%-500%；price 向目标价移动（速度=volatility）
- 城市繁荣度 0-100：战争/天灾降、通商/投资升；决定任务报酬倍率 ×0.5~1.5、强者驻留概率
- 商人职业专属：囤积/套利/垄断 + 战争财与平价赈济抉择（w64_eco_war* 扩展位）

## 七、玩家介入层（goals / fame / karma）

- 目标计划栈（S.worldGoals，ID 规则判定，函数不入存档）：war_见证战事终结 / disaster_end / election
- 世界级名声（S.worldFame）：mercy 仁名 / terror 凶名 / legend 传奇 / scholar 博名（各 0-100）
- 因果链（S.w64Karma，ID 规则，延迟触发）：karma_rescued（救援回响 14 天）/ karma_looted（旧债 21 天）/ karma_bandit（江湖 2 天示例）
- 因果只记 {id, fireDay}，效果在 w64_karmaFire 按 ID 规则表执行（存档安全）
