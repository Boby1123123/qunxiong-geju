# 事件表 v64 — 世界局势事件清单

> 引擎级事件（w64_* 节点 + 广播/传闻/编年史），全部经 v47 worldTick 链结算。
> 动态文本（势力/战争/天灾/局势随状态变化）由节点函数生成，此处列静态骨架。

## 一、战争介入（w64_war_*）

| 节点 | 触发 | 内容 |
|---|---|---|
| w64_war_join | 世界面板"奔赴前线"（w64_joinWar） | 前线动态战况：对峙双方、上一场结果、当前是否已参战；四选（领 A 军牌/领 B 军牌/观战/离开） |
| w64_war_sideA | 选择领 A 军牌（STR 判定） | 设 S.w64Side + 立目标"见证战事终结"；号角吹响，走向战场 / 退缩 |
| w64_war_sideB | 选择领 B 军牌 | 加入另一方，火光下的营地 |
| w64_war_observe | 观战 | 高坡看两军旗子，收尸的人走得很慢 |
| w64_war_return | 离开前线 | 回程，回到 fc_jiaohui_entry |

## 二、天灾响应（w64_dis_*）

| 节点 | 触发 | 内容 |
|---|---|---|
| w64_dis_respond | 世界面板"前往处理"（w64_disNode） | 当前天灾实况：烟火是灰的、有人不肯走；四选 |
| w64_dis_rescue | 救人（CHA 判定） | 效果：rescue（mercy+8/purity+5）；挂因果 karma_rescued（14 天回响）；村里立了块无字碑 |
| w64_dis_loot | 搜刮（AGI 判定） | 效果：loot（terror+8/corruption+5/gold+80）；挂因果 karma_looted（21 天旧债） |
| w64_dis_study | 观察记录 | 效果：study（scholar+6）；本子背面写"下一次要能提前看见" |
| w64_dis_leave | 离开 | 效果：leave（无后果）；走得很快，不想回头 |

## 三、局势介入（w64_sit_*）

| 节点 | 内容 |
|---|---|
| w64_sit_node | 世界面板局势条目"介入"按钮（w64_sitNode）：按当前局势 kind 给双分支 |
| w64_sit_done | 结算：w64_sitResolve + 按 S.flags 手动结算数值（famine 赈济/囤积、border 和平/点火、doctrine 辩论/焚书、treasure 寻宝/卖图、omen 调查/安抚、marriage 撮合/搅黄） |

6 局势种子（situSeeds）：border 边境摩擦（关系 ≤-30 自动开战）/ famine 粮荒 / marriage 通婚提议 / doctrine 教义之争 / treasure 宝藏传闻 / omen 深渊预兆。

## 四、广播与传闻

- 所有引擎事件经 `w64_broadcast` → chronicleRecord（编年史）+ S.missedEvents（v46 酒馆传闻回收）+ S.w64Heard 去重（key = w64b_<标题>_<day>）
- 玩家不在场：只收传闻；在场同城：城市事件池追加入口
- 目标达成/搁浅、因果触发均有广播（"你当年立下的目标，今日成了" / "曾有人想做这件事，后来不了了之"）

## 五、动态生成入口

- 世界面板（v57 职业之路页 + v51 修行面板各一"🌍世界"按钮 → w64_worldPanel）：
  关系矩阵表 / 活跃局势（含介入按钮）/ 战争（含奔赴前线按钮）/ 天灾（含前往处理按钮）/ 教廷选举（资助按钮）/ 目标列表 / 行情入口
- 行情面板（w64_marketPanel）：7 商品现价/供需/趋势箭头 + 城市繁荣度条
