# 大陆战争引擎 · 超大型规划（方向一）

> 状态：规划态（待后台万灵谱深度卡收尾后实施）。本文件与《世界设定_v64》《贵族与权柄_设定基座》同权。
> 核心主张：五主线后段的战争不再是被动看剧情——战争是持续运转的机制，玩家可以是佣兵、将领、后勤、外交，也可以只是躲不开战争的难民。

---

## 〇、为什么做战争引擎

现在的战争是脚本：day 到了，剧情说打起来了，玩家看一段，完了。玩家救了一座城，下一周那座城还是那样，好像什么都没发生。

战争引擎要的是：**战争真的在推进，玩家的每个动作都在改变战线**。北境和兽人草原的拉锯不是背景板——战线值会涨会跌，城池会易手，商路会断，粮价会涨，你上次救下的那座城可能在下一次兽潮里沦陷。你在战争里的选择，决定哪些人活着，哪些城还在。

## 一、战线模型（Front Lines）

### 1.1 战线区（初始 3 条，可扩展）

| 战线 | 对峙双方 | 起点 | 联动主线 |
|---|---|---|---|
| 铁门关战线 | 东境↔深渊裂隙（腐化兽潮） | seal 200 前低烈度，200 后激活 | 七锚线（seal 200） |
| 北境草原战线 | 北境王都↔兽人部族 | 兽潮天灾时激活 | 兽人线（orc 280） |
| 圣山外沿战线 | 学院联邦↔兽人萨满势力 | 神谕悬念发酵时激活 | 神谕线 |

### 1.2 战线值（Front Value）

- 每战线一个数值：`-100（我方溃败）~ +100（我方占优）`，初始按势力关系矩阵基线（北境-兽人默认 -30 左右对峙）。
- **变化来源**：
  - 周结算：按双方军力/补给/天灾每 7 天小幅漂移（±1~3）
  - 事件驱动：兽潮、瘟疫、深渊裂隙、五主线推进（大事件 ±10~20）
  - 玩家行为：战役胜负、任务成败、外交调停（±2~8）
- **阈值效应**（硬钩子，写作锚点）：
  - 战线值 ≤ -40：城池易手候选、商路切断、难民潮（触发难民事件链）
  - 战线值 ≥ +40：反攻窗口、敌城可破、战利品丰收
  - 战线值跌破 -70：战区封锁（玩家无法进入，需绕行）——战争的真实代价

### 1.3 城池与商路状态

- 战区城市（铁门关、北境边境堡、草原哨站等）有 `control` 状态：我方/敌方/争夺中。
- 商路状态：畅通/受阻/切断——直接影响市场 7 商品价格（军械 +60 战时就绪、粮食 +40 封锁修正，与既有需求修正模型一致）。

## 二、战争角色（玩家可选）

### 2.1 佣兵
- 接战线任务：守城、袭扰补给线、护送、斥候侦察、斩首行动（敌将/敌酋）。
- 收益：战功（授爵依据）+ 军饷 + 战利品；风险：阵亡读档、伤残（既有伤势系统联动）。
- 写作风格：佣兵是战争的消耗品，装备自己买、命自己保。任务简报只有一句话："东侧箭塔塌了，去堵上，天亮前别让它们进来。"

### 2.2 将领
- 前置：爵位（男爵+）/名声（传颂级）/战功达标，向战区申请指挥权。
- 指挥决策：进攻/固守/佯攻/撤守——每回合一次抉择，影响战线值与伤亡。
- 将领的账：军功与战损同记。打胜了封爵，打崩了掉声望、被追责（教廷借机发难——暗斗线联动）。
- 写作风格：将领桌案上的不是剑，是粮草单。数字会骗人，斥候更会。你信哪一份？

### 2.3 后勤
- 运粮队、军械押运、战地医疗、伤兵营。
- 被袭风险高、战功少，但赚人情——被救的部队会在后续节点还人情（好感/声望钩子）。
- 写作风格：战争打的是后勤。一车粮草运到前线，比十个骑士砍人有用。

### 2.4 外交
- 调停、联盟、煽动（挑动双方火并）、割地换和平。
- 与势力关系矩阵直接联动：调停成功 → 双方关系 +；煽动 → 关系 -。
- 写作风格：谈判桌上的战争，比战场上更血腥。签字的笔尖一顿，就是几千条命。

## 三、战争事件池（WAR_EVENTS_EXT）

| 事件 | 触发 | 内容钩子 |
|---|---|---|
| 城破 | 战线 ≤-40 且城市争夺中 | 巷战、难民、突围抉择；城破后的残城重建（战后世界） |
| 围城 | 战线拉锯期 | 城中粮尽、守城抉择、内奸排查（社交/洞察判定） |
| 敌将约战 | 战线对峙 | 单挑（越级挑战写四段式受创）、赌注（退兵/领地） |
| 叛变 | 随机低概率 | 城守投敌、军需官贪墨、亲信被策反（信任危机链） |
| 援军 | 盟友势力响应 | 精灵援军（月池兵力）、矮人铁砧军械（七锚线联动） |
| 瘟疫入营 | 南境/战时 | 隔离抉择、药草紧缺（药材价格 +30 联动）、军心 |
| 兽潮趁乱 | 兽潮天灾 + 战线 ≤0 | 双重夹击、撤退路线抉择 |
| 谈判 | 双方疲惫 | 交换俘虏、割地、联姻和亲（贵族包联动——和亲=政治婚姻） |

## 四、战后世界（Campaign Fallout）

- 战争结束（一方战线值推至阈值外）→ 战后结算：领土变更、难民安置、重建任务、战犯审判（教廷宗教法庭插手——暗斗线联动）。
- 玩家在战争中的事迹进入编年史与名声系统（方向四联动），歌谣传唱：东境人唱你守城，自由港唱你劫粮，唱的可能是同一件事的两面。

## 五、与既有系统联动总表

| 系统 | 联动点 |
|---|---|
| 五主线（purge/silver/seal/academy/orc） | 战线激活条件与主线 day 挂钩；主线判定不改 |
| 贵族包 P-E 功勋授爵 | 战功→授爵的直接入口（战役级功勋=封爵依据） |
| 王权×教权暗斗（贵族包 P-F） | 战败=教廷发难借口；战胜=皇权坐大；枢机选举被战争结果影响 |
| 势力关系矩阵 | 战争胜负重排敌对/同盟（±10~25） |
| 市场 7 商品 | 军械/粮食价格随战线波动（+60/+40 修正） |
| 万灵谱 | 兽潮天灾接入战线；战区遭遇超凡生物；战争材料（兽皮/兽核）进市场 |
| 天灾调度器 | 兽潮/瘟疫/裂隙/风暴与战线互乘 |
| 编年史/世界状态 | 战争进程写入世界状态仪表盘；城池易手可追溯 |
| 旅途系统（方向二） | 战区商路切断=旅行路段受阻；绕行=新遭遇 |

## 六、技术实现（不触碰引擎红线）

- 新状态：`S.warState = {front:{iron_gate:30, north_steppe:-30, sacred_ridge:0}, cities:{iron_gate:"ours"}, phase:"standoff"}`（存档字段新增，saveVersion=48 不变——引擎对未知字段兜底）。
- 周结算钩子：复用既有周结算机制，追加战线漂移与阈值检查。
- 事件注入：`WAR_EVENTS_EXT` 数组（仿 EVENT_POOL_EXT，day 与五主线错开）。
- 判定：全部走既有 check/tier/effects 格式，不新增判定公式。

## 八、红线

- 不触碰引擎判定公式/choose/存档语义；saveVersion=48 不变。
- 五主线 day 与判定不可改（战争引擎只是"在主线框架内让世界动起来"）。
- 节点只增不降；V66 文风；30 治理词受控；战斗节点必须四段式（蓄势/交锋/受创/转折）。
- 战争不美化：城破有屠杀、瘟疫有隔离、溃败有踩踏——写真实的代价，不写英雄滤镜。
