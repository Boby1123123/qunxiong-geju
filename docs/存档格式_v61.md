## 一、存储格式

| 项目 | 说明 |
|---|---|
| 主键 | elda-qunxiong-v3-save（不变）；槽位 elda-save-slot-*（不变）|
| 值格式 | 压缩档：`lz1:` 前缀 + LZString.compressToUTF16(JSON)；旧明文档：无前缀 JSON |
| 编码 | UTF-16（localStorage 按字符计数的最高效编码）|

## 二、读写路径（三路嗅探）

1. StorageKit.saveToLS：JSON 序列化后经 v61_lzstring 压缩加 lz1: 前缀写入
2. StorageKit.readFromLS / init 读档 / v34 存档面板（3 副本）：v61_lzstring.sniffRaw 嗅探——lz1: 前缀则解压，否则按明文解析并自动重写为压缩格式
3. StorageKit.importJSON：支持明文与 lz1: 压缩两种导入

## 三、导出/导入

- 导出：设置面板「导出存档」→ 明文 JSON（含版本头）→ Blob 下载 el-qx-<日>-<档位>.json
- 导入：设置面板「导入存档」→ 文件读取 → 嗅探明文/压缩 → 校验 ruleset → 写入主键（导入前备份当前档到临时键）
