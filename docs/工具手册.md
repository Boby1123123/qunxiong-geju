# 工具手册（V91-CT）

> 统一入口：`elda <子命令>`（根目录 elda.bat，或 `python tools\elda\elda.py <子命令>`）。
> 更新至三大路线 CT 批（2026-09-09）：elda ci 21 检查器、content/text 命令族、node_graph 标签化图谱。

## 一、命令一览

| 命令 | 作用 | 说明 |
|---|---|---|
| `elda quick` | 快速体检 | eldacheck quick：语法/死链/引用/节点/marker/结构 六项 |
| `elda full` | 全量体检 | **21 检查器**：追加文本/死代码/存档/dialog/分片/世界/战争/叙事/群像/设定/UI/V68/因果账本/节奏战斗/文本治理门禁 |
| `elda ci` | 发布门禁 | 一条命令：src 语法（26 块）→ 权威源幂等 verify → 四路字节一致 → elda full 21 检查器 → 性能预算门（budget.json 6 项） |
| `elda chunks` | 分片构建 | 收编逻辑于 tools\elda\chunks_impl.py（P0-1 起零根目录脚本依赖）：merge_v62 → build_chunks → verify_chunks → chk_syntax |
| `elda sync` | 四路同步 | game→game_check、chunked→index + 字节校验 |
| `elda build` | 权威源闭环 | _build_authority.py：verify=幂等；extract=game.html→src 回拆；build=src→game.html；sync=四路同步。详情见 docs\权威源与构建链_v69.md |
| `elda schema` | 状态 Schema | schema_elda.py：extract/audit/report（docs\状态Schema_v70.md） |
| `elda node` | 节点管理 | nodes_impl.py：节点级命令族 |
| `elda budget` | 性能预算 | budget_impl.py：--print 查看；--reason 更新基线；门禁=game 上限/分片上限/节点下限/死链 0/耗时上限 |
| `elda content` | 内容工具 | 子命令见下（event/quest/dup/chain/causality/stat/new） |
| `elda text` | 文本治理 | 子命令见下（freq/dup/norm/len/names/guard/all） |
| `elda regress` | 冒烟回归 | regression_template.py 一条命令验证"能玩通" |
| `elda serve` | 本地服务 | http://127.0.0.1:8000/index.html（云存档/网络化实测环境；file:// 双轨并存） |
| `elda audit` | 注册审计 | tools\audit_registry.json 顺序跑全部版本审计 |
| `elda stale` | 过时检测 | 未注册脚本/临时产物/缓存/超龄备份 → 清理候选 |
| `elda doctor` | 环境自检 | python/node 版本、文件存在性、四路一致性 |
| `elda ledger` | 结构台账 | 自动生成 docs\结构台账_<日期>.md |
| `elda registry` | 工具注册表 | 打印 tools\registry.json 全部登记 |
| `elda snapshot/diff` | 结构快照 | eldacheck --snapshot / --diff 对比 |

## 六、10 分钟新增一个合规节点（脚手架演练）

**目标**：新增一个支线节点 `bd1_west_entry`，全程 10 分钟内完成并全绿。

1. **生成脚手架**（30 秒）：
   ```
   elda content new --type branch --id bd1_west_entry --vol "西境内容包"
   ```
   产物 `src\data_nodes\dn_scaffold.js`，自动通过 node --check；含 pace/text/options 骨架与 ifFlag/ifRelation 变体注释。

2. **填写正文**（5-8 分钟）：按 V66 文风书写 text 数组（禁 T0-2 治理词：目光/低声/轻轻/微微/缓缓/深吸）；把 options 的 `go` 指向真实存在的目标节点 id（可用 `elda content stat` 或图谱搜索确认）；战斗节点按 docs\战斗节点模板.md 四段式；若埋设/回收伏笔，同步在 dn_causality.js 补账本项。

3. **验证链**（1-2 分钟）：
   ```
   node --check src\data_nodes\dn_scaffold.js        # 语法
   elda ci                                           # 发布门禁（21 检查器 + 预算门）
   ```
   死链/账本/文本门禁全绿即合规。**注意**：dn_scaffold.js 为 dev 模板不进构建；把完成的节点复制到正式文件（如新建 dn_bd1.js）后再跑构建：
   ```
   elda build build && elda build sync              # 或 elda ci 自动 verify
   elda chunks && elda sync
   ```

4. **回归**：`elda regress`（冒烟）+ 浏览器实测（file:// 打开 game.html 推进到该节点）。

## 八、常见故障

| 现象 | 处理 |
|---|---|
| `elda` 命令不存在 | 用 `python tools\elda\elda.py <子命令>` |
| 体检 FAIL 行号偏移 | 先跑 `python tools\eldacheck\eldacheck.py --full` 确认 strip 等长 |
| 节点新增后死链 | `elda full` 看 c_links 死链清单；确认 go 目标存在 |
| 存档读档报错 | `elda full` 看 c_save 仿真；确认 S.saveVersion=48 |
| 分片构建失败 | `elda doctor` 确认环境；`elda chunks` 看错误（实现 tools\elda\chunks_impl.py） |
| 中文路径编码 | Windows PowerShell 用 `python -X utf8`；内联 python -c 含中文/正则必炸，写成 .py 执行 |
| ci 预算超限 | 合法增长用 `elda budget --reason "说明"` 更新基线 |
| text guard FAIL | `elda text guard` 看逐词定位清单，抽样改写；禁止为凑数改动已合规文本 |

## 游戏内节点编辑器（T-N，v92+）

- 入口：顶栏「✎ 编辑」按钮（id=btn-nodeedit）。
- 功能：搜索节点（id/正文关键词）→ 打开编辑（place/text/pace）→ 保存即时生效（当前会话，刷新还原）→ 预览正文 → 导出补丁 JSON。
- 新建节点：编辑器内「新建节点」→ 填 id（字母开头+字母数字下划线）/place/pace/text → 创建并保存。
- 补丁回写（导出后）：把下载的 elda_node_patch_*.json 的 nodes/created 合并进 src\data_nodes\dn_patch.js（数组元素用 <<<>>> 分隔还原），然后走完整验证链（node --check → build → chunks → sync → elda ci → smoke）。
- 与命令行脚手架关系：elda content new 适合批量生成；游戏内编辑器适合单点微调与试写。
