## 使用要求

1. 替换必须在**精确锚点**上进行（str.replace 原文唯一匹配），不做全文正则。
2. 替换后重跑文本质量检查（elda full），确认无新增 FAIL、无死链。
3. 对话语境保留角色说话习惯：强者 / 平民 / 军人用词不同，套用表时注意口吻。
4. 本表可继续扩充（30 → 50 组），新增条目沿用"动作 + 物件 + 环境"三选一原则。
