# 战斗节点四段式模板（CM-4）

> 状态：v91 已落地。本文档定义战斗叙事写作规范，配套检查器：`elda ci` 第 20 检查器「节奏与战斗」（c_pace.py），对 `COMBAT_TEXTS` 校验四段完整性；后续新增 tag=combat 节点按本模板写作即可通过校验。

## 一、四段式结构

| 段 | 职责 | 系统锚点 | 要素要求 |
|---|---|---|---|
| ① 蓄势 | 开打前的对峙/气势，交代战力差与心理 | `tone_*`（oneshot/crush/advantage/slight/equal/disadvantage） | 环境或姿态细节，1-2 句 |
| ② 交锋 | 出手与命中的过程，按结果分档 | `attack_*`（crit/perfect/hit/graze/miss/fumble） | 动作路径 + 结果归因 |
| ③ 受创 | 受伤描写——**本模板核心** | `hit_*`（light/medium/heavy/crit） | 必须含：**来源词**（谁/什么造成）+ **程度词**（伤到什么程度）+ 部位 + 对属性的影响 |
| ④ 转折 | 胜负/脱离的收束 | `victory*` / `defeat` / `flee_*` | 结果 + 代价或余波 |

## 二、受创段强制要素（检查器校验点）

每个受创文本须同时命中：

- **来源词**：攻击 / 重击 / 擦过 / 撞 / 拳 / 刀 / 剑 / 冲击 / 残影 / 箭 / 爪 / 火 / 冰 / 雷 …
- **程度词**：血 / 裂 / 麻 / 退 / 碎 / 飞 / 震 / 剧痛 / 咳 / 渗 / 疼 / 伤 …

缺任一组合 → 检查器输出告警（默认 warn；`--strict` 可升级为 fail）。

### 写作示例（符合规范）

```text
③ 受创（hit_medium）
「你格挡慢了半拍。重击落在护甲上，闷响震得你虎口发麻，连退三步。」
→ 来源：重击 / 程度：麻、退三步 / 部位：虎口 / 属性影响：行动受阻

③ 受创（hit_crit）
「他的速度快得不像真人。你只看见一道残影，然后整个人飞了出去，撞在墙上。」
→ 来源：残影 / 程度：飞出去、撞 / 部位：全身 / 属性影响：失去平衡，下回合判定 -1
```

## 三、四段联动写作规范（越级挑战特别要求）

1. **蓄势段**必须体现实力差（对方从容 vs 自己紧绷），禁止直接"开打"。
2. **交锋段**不得一次命中就结束——先给 1-2 次试探或失败，再给有效命中。
3. **受创段**逐级递进：轻→中→重→致命，来源与部位不许跳级（轻伤不能直接断骨）。
4. **转折段**胜利必须带代价（受伤/失物/时间），失败必须留退路（脱战/被救/悬念）。
5. 受创对属性的影响要落到 S 字段：HP / 体力 / 专注 / 好感（如 rescue 剧情），不得停留在形容词。

## 四、与现有系统对接

- 战斗文本实际由 `startCombat` + `window.COMBAT_TEXTS`（src\script_02.js:3048）生成，四段对应：
  `tone_*` → 蓄势；`attack_*` → 交锋；`hit_*` → 受创；`victory/defeat/flee_*` → 转折。
- 新增战斗叙事优先扩展 COMBAT_TEXTS（纯数据），不新增引擎分支。
- 校验命令：`elda full`（含「节奏与战斗」检查器）或 `elda ci` 一键门禁。
