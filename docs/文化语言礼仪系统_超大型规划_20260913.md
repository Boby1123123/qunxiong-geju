# 文化·语言·礼仪系统 · 超大型规划（方向三）

> 状态：规划态（待后台万灵谱深度卡收尾后实施）。本文件与《世界设定_v64》《贵族与权柄_设定基座》同权。
> 核心主张：大陆不是"所有人说普通话"。语言是社交与情报的武器，礼仪是贵族的第二层皮肤，禁忌是踩了就要付出代价的文化地雷。玩家听得懂精灵语，才能在月祭上听见真正的密语；行礼错一次，整场宴会都在笑话你。

---

## 〇、为什么做文化语言礼仪系统

现在的世界：精灵说通用语，矮人说通用语，连兽人都说通用语。对话永远是"他说道"。玩家到了精灵国，和到了东境没有区别。

这套系统要的是：**每个地方有每个地方的说话方式、待客规矩、碰不得的逆鳞**。语言让你听得懂，礼仪让你进得去，禁忌让你活下来。它和贵族内容包是同一个世界的两面——贵族包给了你爵位和家徽，这套系统给了你"怎么当贵族"。

## 一、语言系统

### 1.1 语种清单

| 语种 | 使用者 | 获取途径 | 独特价值 |
|---|---|---|---|
| 通用语 | 全大陆 | 默认 | 人人会 |
| 精灵语 | 精灵（银月祭坛/月池） | 学院课程/精灵 NPC 教学/林区沉浸 | 月祭密语、精灵情报、与女王/古树议会直接交流 |
| 矮人语 | 矮人（铁砧议会/山堡） | 铁砧议会课程/宗匠收徒 | 矮人交易（只会通用语的被抬价）、矿道密语、锻礼祷词 |
| 兽人图腾语 | 兽人部族 | 草原沉浸/萨满教学 | 部落会议旁听、图腾纹样解读、大汗宴席礼仪 |
| 古语（封印语） | 教廷圣职/学者 | 教会学校/古卷研习 | **破译七锚铭文/封印碑文（七锚线核心钩子）**、教廷唱祷 |
| 深渊语（禁忌） | 深渊教会/腐化者 | 禁忌途径（声望代价） | 听懂深渊低语、仪式打断、**学习本身被教廷记为异端** |

### 1.2 语言等级（粗通 1 / 流利 2 / 精通 3）

- **粗通**：捕捉关键词（NPC 用母语密谈时，只显示"你听懂了一个词：城、粮"）
- **流利**：完整听懂密谈（解锁情报选项）；能进行日常交易
- **精通**：能模仿口音套话（伪装身份）、能读写密信、能破译铭文（古语精通=封印线专属钥匙）

### 1.3 学习途径

- 学院课程（付费/学期制，与学院五学年衔接）
- NPC 教学（好感门槛：精灵语需林歌好感 40+，矮人语需铁砧议会某宗匠好感，兽人语需灰鬃线）
- 沉浸习得（在相应地区累计驻留时间自动升级粗通→流利）

### 1.4 语言的功能性（写作时兑现）

1. **情报**：母语密谈截获——精灵近卫私下说的话、矮人议价的底价、兽人战酋的部署
2. **支线解锁**：矮人宗匠只跟会矮人语的人谈秘传锻造（万灵谱打造联动）；精灵古树议会外会记录用精灵语
3. **破译**：古语=封印语（七锚线）：遗迹铭文、七锚碑文、深渊封印法阵——不会古语，这些线索就只是"看不懂的石头"
4. **社交门槛**：教廷仪式古语唱祷（背错=大不敬）；贵族宴席间精灵语敬酒是身份象征（贵族包联动）
5. **伪装**：精通口音可冒充当地人（潜入/套话/避开追捕）

## 二、礼仪系统（社交判定扩展）

### 2.1 礼仪场合清单

| 场合 | 地点 | 核心礼仪点 |
|---|---|---|
| 宫廷朝见 | 承天城帝京 | 觐见礼、御座朝向、自称措辞 |
| 贵族宴席 | 全大陆贵族宅邸 | 席位次序（虚职/实职）、敬酒辞、家徽识别 |
| 教廷礼拜 | 圣辉城/各地大教堂 | 祷告词、圣礼姿态、佩刃禁令 |
| 精灵月祭 | 银月祭坛/月池 | 赤足入祭、禁铁器、献礼习俗 |
| 矮人锻礼 | 铁砧议会/山堡 | 赠锤礼、炉火祝词、禁提背叛 |
| 兽人图腾会 | 圣山/黑石部族 | 图腾敬礼、萨满席位、禁踩图腾纹样 |

### 2.2 礼仪判定

- 属性：CHA（魅力）+ 技能 `etiquette`（礼仪）/`lore`（学识）/语言等级 + 爵位等级（贵族包联动：虚职在实权场合被"轻看半格"）
- 结果分层（tier 复用）：
  - 大成功：被引为知己（声望 +、解锁深谈）
  - 成功：得体（无损耗）
  - 失败：失礼（声望 -、被试探/被嘲笑）
  - 大失败：**踩禁忌**（关系危机 -20~-40，特定场合逐出场馆）
- 礼仪知识获取：请礼仪教师（花钱）、出席场合学习（每次 +）、宫廷书籍（贵族包 P-E 家徽学）

### 2.3 文化禁忌与习俗（文化地雷）

| 族群/地区 | 禁忌 | 后果 |
|---|---|---|
| 矮人 | 提"背叛"、拒绝赠锤 | 违约之仇入账，交易关系断裂 |
| 精灵 | 谈寿命与衰老、月祭带铁器 | 好感 -30，被请出祭典 |
| 兽人 | 踩图腾纹样、在萨满前逞强 | 部落敌意，战酋挑战 |
| 教会辖区 | 礼拜日佩刃、背错祷告词 | 宗教法庭登记（异端嫌疑，暗斗线联动） |
| 东境 | 御座前背对皇帝、自称"朕" | 宫廷逐出/教廷与皇权博弈筹码 |
| 西境 | 风暴季说不吉利话 | 当地人疏远（迷信） |

### 2.4 口音与称呼系统

- **口音**：东境官话/自由港俚语/北境卷舌/学院腔——玩家选择口音影响 NPC 初印象（伪装身份玩法：选错口音=露馅判定）
- **称呼**：NPC 按玩家爵位/名声/关系动态切换称呼——"那个外地人"→"先生"→"阁下"→"大人"→"殿下"→"老友"——**称呼变化是声望最直观的可视化**（编年史联动）
