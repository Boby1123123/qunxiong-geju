# 旅途与荒野系统 · 超大型规划（方向二）

> 状态：规划态（待后台万灵谱深度卡收尾后实施）。本文件与《世界设定_v64》《贵族与权柄_设定基座》同权。
> 核心主张：旅行不是点对点瞬移——路是走出来的，每一段路都有故事。你在路上救的陌生人、绕过的沼泽、错过的驿站，都会变成记忆（编年史）与回报（支线/声望）。

---

## 〇、为什么做旅途系统

现在的旅行：点一下城市名，到了。中间的路不存在——没有风沙，没有露宿，没有拦路的匪，也没有你在驿站炉火边遇见的人。

旅途系统要的是：**路本身是玩法**。从自由港到北境王都要走七天，这七天里会发生什么，取决于你怎么走、在哪扎营、信不信那个搭车的旅人。万灵谱里那 88 种兽、92 种草，不该只活在图鉴里——它们住在路上。

## 一、路程模型（Route Segments）

### 1.1 路段拆分

长距离旅行拆成"路段"，每段有独立身份：

| 干线 | 路段示例 | 特征 |
|---|---|---|
| 自由港→北境王都 | 商路（2 天）→ 灰脊隘口（1 天）→ 苔原（2 天）→ 王都郊野（1 天） | 商路安全/隘口匪患/苔原严寒 |
| 东境→西境 | 皇道（3 天）→ 元素荒原边缘（2 天）→ 西境三城（1 天） | 皇道车马多/荒原风暴 |
| 自由港→学院 | 海岸线（2 天）→ 森林（2 天）→ 学院（1 天） | 海岸遇海盗/森林有精灵哨站 |
| 北境→圣山（兽人） | 雪原（3 天）→ 黑石丘陵（2 天）→ 圣山外围（1 天） | 雪原兽潮/丘陵部落 |

- **首走必过**：第一条走过的干线，每段都有一段剧情（遭遇/见闻/抉择），累计 3000+ 字（符合用户字数偏好）。
- **快速通行**：走过的路段可"快进"（消耗口粮 + 低概率随机事件），但快进会错过路途支线。

### 1.2 路段属性

- 距离（天）、危险度（1-5）、天气影响（暴雪封路/暴雨泥泞/沙暴迷路/烈日脱水）
- 遭遇表：每段一个遭遇池（按地域×时段×危险度加权）

## 二、扎营系统

### 2.1 露营决策（每夜一次）

- **生火**：暖和、安全（野兽怕火）、能煮食，但火光暴露位置——夜袭概率升
- **摸黑**：隐蔽、省柴，但寒冷（体力/意志压力）且野兽可能摸过来
- **守夜轮换**：减少夜袭损失，但全员疲劳（次日遭遇判定 -）
- **搭营技巧**：找背风坡/近水源/高地——生存/感知判定，失败=潮湿或暴露

### 2.2 夜晚事件池

- 荒野生物袭击（**万灵谱直接引用**：按地域从 BEAST_ENCYCLOPEDIA_EXT 抽取——苔原雪狼、森林影豹、荒漠沙蝎）
- 流民求救（救/不救——因果链 + 名声）
- 神秘旅人（夜谈——情报/好感/身份反转三选一的叙事钩子）
- 梦境（神谕托梦/深渊低语/已故之人——与封印线、神谕线咬合的精神系钩子）

### 2.3 营地记忆

- 玩家营地的选择会留下痕迹：同一个地点第二次扎营，可能遇见上次的余波（烤焦的树、没埋净的灰、被狼翻过的营地）——世界记得你。

## 三、驿站与商队

### 3.1 驿站网络

- 功能：补给（粮/水/火绒）、马匹交易、情报交换（驿站传闻=事件预告）、悬赏榜（万灵谱悬赏联动）、信使（寄信=好感支线联动）
- 驿站主人：各有故事（退役老兵/逃妾/暗桩/情报贩子——每个驿站 1 个可深挖 NPC）

### 3.2 商队同行

- **护送任务**：加入商队当护卫（白驼线联动），途中遭遇劫匪/野兽/勒索
- **搭车**：付路费免部分遭遇，但受商队行程约束（不能中途乱逛）
- **劫商队**：恶名路线（战利品 vs 名声/关系——与因果链 karma_looted 联动）

## 四、天气与地形

### 4.1 天气影响行进（扩展既有 v92_weatherLine）

- 暴雪：封路（改道/扎营等待）
- 暴雨：泥泞（耗时 +1 天）、山洪（改道）
- 沙暴：迷路（方向判定失败=偏离路线，进遭遇）
- 烈日：脱水（饮水管理）
- 天气句仍由引擎注入，但旅途节点可因天气产生**实际影响**（不只是氛围）

### 4.2 地形遭遇差异

| 地形 | 专属遭遇 |
|---|---|
| 森林 | 伏击、精灵哨站、迷路（树影）、猎物 |
| 荒漠 | 缺水、幻象（海市蜃楼=深渊钩子）、废墟 |
| 山地 | 落石、隘口土匪、矮人矿道入口（铁砧线） |
| 沼泽 | 毒雾（意志判定）、沉陷、巫婆/隐修者 |
| 雪原 | 兽潮踪迹、冻尸（带线索）、极光（神谕意象） |

## 五、旅途事件链（Road Event Chains）

单段遭遇可以是连环的：救下被劫商队的幸存者 → 他求你护送他妹妹的遗物去某城 → 遗物是一封密信 → 密信指向一个叛变贵族 → 你在到达目的地时被伏击……（3-5 节点闭环）

设计原则：旅途事件不是孤立随机，**每个"在路上"的人都有来处和去处**。遇见的每个陌生人，都可能在下一条线里再见面。

## 六、与既有系统联动总表

| 系统 | 联动点 |
|---|---|
| 万灵谱 | 遭遇池直接引用 88 兽/92 草；路遇超凡植物可采集（炼金/市场联动）；狩猎权=贵族特权（贵族包） |
| 悬赏/拍卖/打造（万灵谱系统层） | 驿站悬赏榜接单；路获材料进拍卖行 |
| 贵族包 | 领地巡视（封地不在主城时，去领地=走旅途）；战区商路切断（战争引擎） |
| 战争引擎（方向一） | 战区路段受阻/绕行/战时护送 |
| 因果链（karma 系列） | 劫商队/救流民/弃伤者——善恶因果延迟触发 |
| 好感支线 | 护送 NPC 途中好感事件（林歌/灰鬃/白驼等可同行） |
| 编年史/手记 | 旅途见闻写入冒险手记；重要旅伴记入编年史 |
| 天气/时段 | 天气影响行进；夜行遇敌率升高 |

## 七、技术实现（不触碰引擎红线）

- 新状态：`S.route = {path:["seg_1","seg_2"], pos:0, supplies:5, camp:{fire:true, watch:false}}`（未知字段兜底，saveVersion=48 不变）。
- 路段节点模板：`{tag:"road", place:"路线 · 路段", text:[...], options:[{t:"继续赶路", go:...},{t:"扎营", go:...},{t:"探查四周", go:...}]}`——旅途节点统一带"探查/扎营/赶路"三选，内容按段定制。
- 遭遇表：`ROAD_ENCOUNTERS` 配置（地域→兽/草/人/天气四类池），引用 BEAST/HERB 图鉴 id。
- 全部判定走既有 check/tier/effects。

## 九、红线

- 不触碰引擎判定公式/choose/存档语义；saveVersion=48 不变。
- 遭遇池引用图鉴 id 必须存在（死链检查）；新地名登记 REGIONS 或按内容包流程挂入口。
- 节点只增不降；V66 文风；30 治理词受控；天气句由引擎注入不自带。
- 旅途事件可残酷但要有选择空间——玩家被劫、被袭、被背叛都要有"另一条路"的痕迹（选项语义不删）。
