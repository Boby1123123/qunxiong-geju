## 二、构建闭环命令（新增）

```powershell
cd "D:\1pao tuan\群雄割据"
python _build_authority.py extract    # game.html -> src\（head + script_00~18 + 间隙）
python _build_authority.py build      # src\ -> game_built.html（不覆盖权威源）
python _build_authority.py verify     # 幂等门：build(extract(game.html)) == game.html（字节级）
python _build_authority.py sync       # 四路同步 + 字节校验
elda build verify                     # 统一入口（等价上面 verify）
elda build sync                       # 统一入口（等价上面 sync）
```
