# 万灵谱·物种深度卡 规格说明（v109+）

## 数据结构

所有深度卡以 `window.BEAST_DEPTH_CARDS` / `window.HERB_DEPTH_CARDS` 全局对象追加，
多文件共存时用 `Object.assign` 合并，不覆盖既有条目。

```javascript
window.BEAST_DEPTH_CARDS = Object.assign(window.BEAST_DEPTH_CARDS || {}, {
  beast_xxx: {
    stats:    { STR:n, CON:n, AGI:n, INT:n, SPR:n, CHA:n },  // 六维种族值
    traits:   ["特性1（被动天赋+触发条件）", "特性2"],         // 1-3条
    potential:{ cap:"段位上限", path:"凡品→启灵→凝元→化意→宗师→传奇" },
    niche:    { habitat:"栖息地", social:"群居/独居", foodchain:"食物链位置" },
    behavior: { rhythm:"昼夜节律", season:"季节行为", attack:"攻击方式" },
    weakness: { weak:["弱点1"], resist:["抗性1"] },
    loot:     { parts:["部位材料+用途"], market:"市场/打造用途" },
    description: "300-500字白描（V66文风）",
    interactions: [
      { name:"观察", check:"INT+自然", tier:"凝元", result:"成功时的描述" },
      { name:"驯养", check:"CHA+驯兽", tier:"化意", result:"..." }
    ],
    stars: 4,                              // 图鉴星级 1-5
    myth:  "神话原型来源",                  // 北欧/希腊/凯尔特/斯拉夫等
    tags:  { habitat:"xxx", season:"xxx", region:"xxx" }  // 生态联动标签
  }
});
```

## 六维段位基准

| 段位 | 数值范围 |
|------|----------|
| 凡品 | 5-20 |
| 启灵 | 20-40 |
| 凝元 | 40-60 |
| 化意 | 60-80 |
| 宗师 | 80-100 |
| 传奇 | 100+ |

## 写作铁律

1. **V66白描文风**：短句、五感、情绪外化、禁三连排比、禁否定式煽情、禁过度拔高
2. **去AI味**：不写"不仅...而且"、"仿佛...一般"、"宛如"等模板句式；用具体动作和细节代替抽象评价
3. **30治理词避让**：微微/轻轻/缓缓/低声/目光/嘴角/片刻/仿佛/似乎/眼底/心头/喃喃/沉吟/皱眉/深吸/良久/微叹/眸光/不由/下意识/微微一怔/淡淡道/沉声道/轻声道/若有所思/不动声色/隐隐/隐约/些许/身形一闪——每词全书≤30，新内容尽量不用
4. **描述300-500字**：白描生态、外形、行为、与人的关系，不写属性面板式文字
5. **互动≥2种**：观察/驯养/猎杀/采集，带check属性+技能+tier段位判定
6. **神话挂接**：每个物种标注原型来源，描述中可融入但不照搬神话原文
7. **节点只增不降**：不动既有 BEAST_ENCYCLOPEDIA_EXT / HERB_ENCYCLOPEDIA_EXT 条目文本

## 文件命名

- 兽类：`dn_bio_beast_depthN.js`（N=1~4，每批约22种）
- 草类：`dn_bio_herb_depthN.js`（N=1~4，每批约23种）
- 神话：`dn_bio_myth_depth.js`
- 特殊/灵体：`dn_bio_special_depth.js`
