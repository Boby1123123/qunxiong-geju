## 二、层间依赖

- **tools → game**：所有检查器只读 game.html；`elda sync` 写 game_check/chunked/index（game.html 为权威源，不被他工具改）。
- **content → core**：节点 N[id] 依赖引擎 writeNext/choose/advanceTime 判定公式；数据对象经 window 导出供引擎读取。
- **core → content**：引擎只按 id 寻址节点，不内嵌业务数据（JOBS/STRONG 等数据对象在 content 层定义）。
- **docs → 全部**：QA 报告引用 tools 输出与 game 状态；审计脚本硬编码 game.html 路径。
- **禁止反向依赖**：tools 不得 require docs；content 不得依赖 tools（浏览器运行时无 Python）。
