## 〇、框架总览

**一句话**：把「超凡生物」从背景板升级为贯穿 **战斗 → 成长 → 经济 → 装备 → 势力 → 主线** 的完整生态层，让大陆上每一只兽、每一株草、每一道灵体都有可狩猎、可交易、可打造、可深挖的价值。

**与既有系统的关系**（不是新加孤岛，而是给每个既有系统接上「生物材料」这根水管）：

```
                 ┌─────────────── 万灵谱（超凡生物生态层）───────────────┐
                 │  四纲分类 × 六阶位 × 五稀有度 × 部位材料体系          │
                 └──┬──────┬──────┬──────┬──────┬──────┬──────┬──────┬──┘
                    │      │      │      │      │      │      │      │
                 战斗   境界   市场   装备   功能   天灾   势力   主线
                (四段式)(LMS)(TRADE)(锻造)(驯养)(调度器)(九域)(五主线)
```

**既有锚点（框架直接复用，不重造）**：
- 境界 LMS（script_01.js）：凡人 0 / 启灵 100 / 凝元 300 / 化意 800 / 宗师（xp 阈值）
- 市场 TRADE_GOODS_V92（dn_trade.js）：16 商品，**已有兽核 core=22 / 兽皮 hide=9**；TRADE_MARKET 多城行情系数
- 坐骑 MOUNTS_DATA / 宠物 PETS_DATA（script_02f.js v21 收集系统）：骏马/骆驼/狮鹫/幼龙 + wolf_pup/小精灵/史莱姆
- 材料雏形（script_02f 贤者之石实验）：启灵草×3 / 凝元丹×1 / 化意果×1 / 宗师心得×1
- 伏笔材料（script_02b）：灵魂之灰 / 深渊之血 / 黄林晶的眼泪
- 传奇级超凡野兽：鬃吼（script_02d，「百兽之王·传奇级超凡野兽，不算人类」）
- 天灾调度器五类：兽潮/瘟疫/深渊裂隙/元素风暴/旱涝
- 账本：七锚（led_anchor_01~07）/ 深渊封印（led_f1_seal）/ 晨星之泪（led_a3_04）

## 一、基础体系设计

### 1.1 四纲分类（生物谱系树）

| 纲 | 亚类 | 代表示例（拟新增） | 共性特征 |
|---|---|---|---|
| **超凡动物纲** | 兽/禽/虫/水族 | 北境雪鳞狼、草原雷鬃马、西境风隼、死亡沙漠沙蛹蝶、月池银鲛 | 可狩猎/可驯养/材料在血肉骨鳞爪牙角 |
| **超凡植物纲** | 灵草/灵木/菌/藤 | 启灵草（既有）、凝元花、化意果（既有）、血藤、魂菇、月桂木 | 可采集/可培育/材料在根茎花实灵液 |
| **特殊生物纲** | 异种/元素造物/深渊魔物/封印生物 | 深渊黑鳞魔物（既有）、风暴元素体、雷晶傀儡、铁砧地底蠕兽、钟楼地下的"它" | 战利品高危/部分不可驯/材料极端稀缺 |
| **灵体纲** | 怨灵/英灵/元素灵/神性残响/器灵 | 钟楼第十三下的"声音"、铁门关英灵、银月祭坛月灵、铁牌器灵 | 免疫物理/需灵魂系手段/可契约役使 |

### 1.2 六阶位（对齐 LMS 境界，战斗/材料/价格共用一把尺）

| 阶位 | 对应玩家境界 | 掉落材料档 | 参考强度 |
|---|---|---|---|
| 凡品 | 凡人境 | 无灵材（普通兽皮） | 普通人可猎 |
| 启灵 | 启灵境 | 启灵级（灵草/兽核下品） | 1~3 名启灵者 |
| 凝元 | 凝元境 | 凝元级（凝元花/兽核中品） | 小队凝元 |
| 化意 | 化意境 | 化意级（化意果/魂核） | 化意强者 |
| 宗师 | 宗师境 | 宗师级（宗师心得/龙鳞） | 宗师级 |
| **传奇** | 传说级（无玩家对应） | 唯一材料（鬃吼之牙等） | 鬃吼=传奇级超凡野兽 |

### 1.3 五稀有度（影响价格系数/图鉴点亮/掉落保底）

常见（×1）→ 少见（×3）→ 稀有（×10）→ 传说（×30）→ 唯一（×100，仅账本登记生物）

### 1.4 部位材料体系（材料 = 生物 × 部位 × 阶位）

| 部位 | 属性倾向 | 主要用途 |
|---|---|---|
| 血肉 | 炼药/烹饪 | 回复药、属性食物 |
| 骨 | 锻造（武器框架） | 骨刃、骨杖 |
| 鳞/皮 | 护甲 | 鳞甲、皮甲 |
| 羽 | 轻装/箭矢 | 飞行附魔 |
| 爪牙/角 | 武器锋刃/药引 | 兽牙匕首、角磨粉 |
| 心核/兽核 | 法杖核心/药炉燃料 | 元素增幅（兽核 core 既有） |
| 魂核（灵体） | 灵魂系装备/契约 | 役使媒介 |
| 灵液/根茎/花实（植物） | 炼丹/炼药主料 | 晋级丹配方 |
| 菌丝/灵纹（特殊） | 附魔墨水/封印材料 | 附魔、刻印 |

## 二、八大支柱模块（详细设计）

### 模块 1 · 万灵图鉴（生态层）

- **图鉴面板**：扩展 script_02f v21 收集系统——按四纲六阶分类页签，点亮条件 = 遭遇/狩猎/采集/契约 各记一次，点亮数解锁图鉴奖励（全图鉴收集线）。
- **区域生态表**：九域 × 四纲 × 阶位分布（每个区域登记 3~6 种代表生物，与 REGIONS/九域地图联动）。
- **习性/弱点/食谱**：每生物 3 字段（昼伏/群居/食谱→克制链），战斗节点消费。

### 模块 2 · 狩猎与遭遇（战斗层）

- **战斗节点四段式**（V66 硬规范）：蓄势→交锋→受创（来源+部位+程度+属性影响）→转折；越级挑战先示弱卖破绽再爆发。
- **弱点克制表**（按属性×生物属性，与元素魔法/职业联动）：火克木、光克灵体、雷克水族、银器克怨灵、铁器克深渊魔物等。
- **特殊生物机制**：灵体免疫物理（需 soul 技能/灵魂系法术）；元素造物反伤（需先破核）；深渊魔物污染（san 惩罚）；封印生物（需铁牌/锚印 才可开战——七锚联动）。

### 模块 3 · 材料掉落（产出层）

- **部位掉落表**：生物×阶位→掉落部位清单 + 概率档。
- **掉落判定**：战斗后掉落节点结算（可给 survival/detect 加成；大师级狩猎者保底）。
- **战利品节点**：每种生物一条「剖取战利品」分支（可当场用/带回城卖/留作材料）。

## 五、数值与平衡框架

- **材料价格** = base × 阶位系数（启灵×1/凝元×3/化意×8/宗师×20/传奇×60）× 稀有度系数 × 天灾修正（1.5~3×）
- **掉落保底**：普通生物必掉 1 基础部位；稀有以上 50% 掉第二部位；传说必掉心核/魂核
- **晋级丹成功率**：alchemy/medic 判定 tier（ok=60% 成品 / crit=100% / fail=材料损半）；配方材料可重复获取（防死档）
- **装备词条数值**：每材料 1~2 词条，数值按阶位档位（例：启灵级 +2~+4 属性，宗师级 +10~+15）

## 六、红线与兼容

1. **不触碰**：判定公式 / writeNext 核心语义 / choose / 存档结构语义；saveVersion=48 不变。
2. **只增不降**：节点只增不降；文本不删句不改既有选项语义；既有 TRADE_GOODS/事件/账本项一律不动，只追加。
3. **设定一致**：与 8 势力矩阵 / 五主线 day / 七锚 / 铁牌 / 神谕 / 金秤 / 鬃吼 / 晨天 严格一致；新生物不违背既有名称（鬃吼=传奇级已定，不可降格）。
4. **只做桌面端**：不做移动端适配，移动端内容一律不引入。
5. **账本铁律**：新伏笔必须登记 led_bio_*；不删既有项；open 只核销不造假。
6. **V66 文风**：战斗四段式受创必写；30 治理词每词全书 ≤30；引号成对。
