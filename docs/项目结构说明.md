## 二、核心文件说明

| 文件 | 作用 |
|---|---|
| `game.html` | 唯一交付物。内联全部剧情节点（2618个）、引擎函数、UI样式。双击即可运行，存档走 localStorage（键 `elda-qunxiong-v3-save`）。 |
| `story_elda_*.py` | 55 个数据卷，按版本线组织（a~bk）：出身序章 / 学院 / 大陆 / 城市 / 旅行 / 同学 / 封印 / 深渊 / 时间系统 / 多学院体系 / 伏笔等。 |
| `engine_elda.py` | 引擎：节点渲染、选项跳转、判定、战斗、存档。 |
| `mech_elda.py` | 机制：属性/职业/修炼/经济/时间（v26）/天气等数值系统。 |

## 三、验证流程（改动后必跑）

> 更新（U1 20260909）：旧验证链脚本（_v39_extract / _chk_* / _check_dead_links / _audit_deep13）已随历史脚本归档移入 backup\scripts_archive\，当前验证链统一走 elda 工具链。

```powershell
cd "D:\1pao tuan\群雄割据"
python tools\elda\elda.py build verify   # 权威源幂等（src ↔ game.html 闭环）
python tools\elda\elda.py chunks         # 分片构建 + 完整性 + 语法（收编于 chunks_impl）
python tools\elda\elda.py sync           # 四路同步 + 字节校验
python tools\elda\elda.py ci             # 发布门禁：src 语法 → 幂等 → 四路 → full 18 检查器 + 预算门
```

详细说明见 `README_构建验证.md` 与 `docs\权威源与构建链_v69.md`。
