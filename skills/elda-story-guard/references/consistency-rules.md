# 一致性规则清单（consistency-rules）

终检人工清单——逐项打勾，任一违规立即停改，不降级不绕行。

## 1. 人物（OOC 检查）
- [ ] 既有角色行为符合人设表（见 setting-bible 人物表）：如灰袍若耶谨慎务实、艾德蒙质疑者立场、枢机·克莱门特严守教条不可轻易被说动。
- [ ] 角色口吻一致：同一人物在前后节点的用词、称呼、态度不漂移（"同人物口吻一致"是 T0-2 既定要求）。
- [ ] 不新增与关键角色顶替/重名的"同名异人"。
- [ ] 好感里程碑 60 挚友 / 80 恋人 / -60 死敌——支线推进符合既有关系曲线。

## 2. 地名与地理
- [ ] 地点用既有名（自由港/铁门关/晨天城/西境三城/死亡沙漠五城/银月祭坛/铁砧议会/圣山 等），不自造同义异名。
- [ ] 新地点要么已入 REGIONS（script_01.js:15），要么走内容包流程（补 REGIONS + script_02.js 入口 + dn 文件）。
- [ ] 区域风貌一致：西境=元素风暴荒原、死亡沙漠=盐湖/封印柱、光明教会=圣痕司/审判庭、东境=帝京文脉。

## 3. 时间线
- [ ] 五主线 day 不冲突（purge 60 / silver 120 / seal 200 / academy 250 / orc 280）；新事件 ±5 天不撞同主题。
- [ ] 季节/昼夜（where 字段）与地点环境一致；`advanceDays` 后的日期推进不被新节点绕开。
- [ ] 事件池 day 单调合理（不出现后段事件 day 早于前段主线）。

## 4. 势力与政治
- [ ] 8 势力关系等级不被新剧情无因果反转（abyss 敌对基线、church 与 academy 中立摩擦、free 商业中立）。
- [ ] 净化令波及玩家时走"藏匿/抗争/作证"三路（BD-3 先例），不改变 purge 主线判定。
- [ ] 枢机选举两候选立场不混淆（克莱门特=严、奥黛拉=宽）。

## 5. 经济与市场
- [ ] 商品价格波动符合市场模型（军械战争+60、药材瘟疫+30、粮食兽潮/旱涝+40）。
- [ ] 新增买卖选项的 effects.gold 数值与既有物价体系量级一致（银月/金龙单位不错乱）。

## 6. 存档与状态字段
- [ ] 新功能一律独立键或默认值；不新增对 S 既有字段语义的改动（saveVersion=48、applyDefaults 兜底链不变）。
- [ ] 引用只读状态（S.day/curCity/visited/flags/npcRelations/settings）时字段名与 engine 一致（如 S.settings.memoryInjection、S.settings.pagedReading）。

## 7. 文本质量（与 elda-content-author 共用）
- [ ] 30 治理词每词 ≤30 处；中文引号成对；无英文引号包中文。
- [ ] 战斗节点含受创段（来源+部位+程度）；越级挑战先示弱后爆发，不平白战胜。
- [ ] 新增文本不重复既有句式/剧情桥段（"故事内容不能多次重复"）。

## 8. 伏笔账本
- [ ] 新伏笔已登记（open 且 plant 成立）；回收项核销（reap 锚点成立才 closed）。
- [ ] 账本 38 项只增不删；既有 closed 不回退 open。
- [ ] 涉及冻结设定词时该词出现在所属卷域文件（否则 ci FAIL）。

## 机器兜底
- 上述 1-8 的机器可查部分由 `elda content causality / chain / dup / text guard / ci` 覆盖；人工部分（OOC、口吻、重复桥段）由本清单兜底——**机器全绿 ≠ 设定一致**，人工清单必须走完。
